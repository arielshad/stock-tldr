<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">KOSPI +17.9% to 6,695 — Largest Single-Day Gain in Korean Market History</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">KOSPI logs its biggest one-day gain ever as Asia AI trade snaps back on Microsoft + Amazon cloud blowouts.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
South Korea's KOSPI closed Friday July 31 up 17.9% at 6,695.45 — its largest ever single-day percentage gain, eclipsing the prior ~12% record from October 2008. Memory chip giants SK Hynix (+30%, daily up-limit) and Samsung Electronics (+28%) led as Asia's AI complex rebounded across the board.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The rally followed Microsoft reporting Q4 FY26 Azure growth of 43% cc and Amazon reporting AWS +36.7% Y/Y to $42.2B, both signaling hyperscaler AI capex is still translating to cloud revenue. That directly reversed the AI-bubble narrative that had pushed KOSPI down 17% over the prior three sessions on China (CXMT) competition fears.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The single-day move ranks as the largest ever recorded in a G20 equity index and confirms that memory and Korean semi-cap exporters remain the highest-beta expression of US hyperscaler AI capex. Nikkei 225 added 4%, Taiwan Taiex +8%, TSMC ADR +10%, SoftBank +13.8% — the full Asia AI complex repriced in one session.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI semi-cap traders and EM equity desks tracking the Korea/Taiwan memory complex.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Bank of Japan's Policy Board voted 8-1 on Friday July 31 to keep its short-term policy rate at 1.00%, unchanged from the June hike (from 0.75%) that was the highest level since 1995. Board member Hajime Takata dissented, calling for an immediate 25bp hike to 1.25%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The July Outlook Report warned that core CPI ex-fresh-food is likely to run "clearly above 2%" in H2 FY2026 — a hawkish upgrade from prior guidance. Governor Ueda kept his explicit tightening bias; Capital Economics held its non-consensus call for BOJ to 2.0% by end-2027, and Sompo's Masato Koike said October is now more likely than December for the next hike.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The BOJ is now the only major central bank still actively tightening — in direct contrast to the Fed (held with three hawkish dissenters July 29) and the ECB (held July 23). An October hike would risk unwinding USD/JPY carry trades and pressuring Nikkei tech names.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, yen carry desks, and JGB players watching the BOJ-Fed divergence trade heading into the September MPM.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Chevron's first full post-Hess quarter delivers best profit in six-plus years on record barrels and record debt paydown.</p>

<strong style="color: #f7ff00;">What is it?</strong><br>

</p>
