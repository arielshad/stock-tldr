<strong style="color: #f7ff00;">What is it?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The move is the largest single-day gain ever recorded in a G20 equity index, confirming Korean memory names as the highest-beta expression of US hyperscaler AI capex. It sets the stage for how NVDA, MU, and AVGO trade ahead of NVDA's own August print.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US Q2 2026 Employment Cost Index +0.9% Q/Q beats +0.8% est — private-industry real wages -0.4% Y/Y, first Y/Y decline since 2022 as Iran-conflict energy prices reignite CPI</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">The Fed's preferred wage gauge cools less than expected as real wages for private workers fall for the first time in four years.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BLS released the Q2 2026 Employment Cost Index on Friday July 31. Total civilian compensation rose 0.9% Q/Q — one tick above the +0.8% Bloomberg consensus — and 3.4% Y/Y over the four quarters ending June.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The key detail is buried beneath the nominal print: real, inflation-adjusted wages and salaries for private-sector workers fell 0.4% Y/Y — the first Y/Y decline since 2022 — because Iran-conflict energy prices pushed CPI higher through Q2 even as nominal wage growth cooled to ~3%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
ECI is the Fed's preferred mix-adjusted wage measure, so a hotter-than-expected print stiffens the case for the Hammack/Kashkari/Logan hike-dissent camp from the July 29 FOMC. The simultaneous real-wage compression is a consumer-spending headwind that complicates the political calculus for Fed Chair Warsh.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rate-vol desks, and Fed-watchers tracking the path to July NFP (Aug 7), July CPI (Aug 12), and Warsh's Jackson Hole speech.
</p>
