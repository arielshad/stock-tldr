<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US August NFP +162K vs +53K est — nearly triple consensus; Fed Sept-hike odds jump to ~58%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">August NFP hit +162K vs a +53K consensus, unemployment held at 4.1%, and rate-hike odds for the Sept 15–16 FOMC jumped to ~58%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Bureau of Labor Statistics' Employment Situation for August 2026, released Friday Sept 4 at 8:30 a.m. ET. Nonfarm payrolls rose by 162,000 versus a Dow Jones consensus of 53,000 — nearly triple expectations. Unemployment was unchanged at 4.1%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Average hourly earnings rose 10 cents (+0.3% M/M) to $37.75. Prior months were revised up: June went from +20K to +31K and July from -23K to +21K — a net upward revision of 55,000.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The blowout print upended the Sept-hike debate — Waller and Williams had leaned toward a hold. Fed-funds futures moved to ~58% odds of a Sept 15–16 hike; two-year yields rose 4bp to 4.37% and Bitcoin briefly broke $80,000.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Rates desks, macro traders, and FOMC watchers ahead of the Sept 11 CPI and Sept 15–16 FOMC decision.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Iran's security chief signals a coming Hormuz exclusion zone, one day after US Navy sank three IRGC tankers.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Mohsen Rezaei — the head of Iran's Supreme National Security Council — told state TV on Sunday Sept 6 that Tehran will formally declare a 'prohibited zone' outside the Strait of Hormuz in the coming days. It follows Saturday's US CENTCOM strike on three IRGC oil tankers.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Hormuz still carries roughly 9 million barrels per day — about two-thirds of pre-conflict flows. Brent settled Friday +9% w/w at $96.28 on the week's US-Iran tanker exchange; a formalized exclusion zone tightens the war-risk bid further.

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy desks, geopolitics traders, and shipping insurers watching the Brent/WTI spread and tanker re-insurance costs.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">OPEC+ holds October 2026 quotas at September levels — 7 core producers keep combined 31.01 mbd cap; next meeting Oct 4</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">OPEC+'s seven core producers hold October quotas at September levels — combined 31.01 mbd cap, next meeting Oct 4.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The seven core OPEC+ producers — Saudi Arabia, Russia, Iraq, Kuwait, Kazakhstan, Algeria, and Oman — met virtually on Sunday Sept 6 and decided to leave October production quotas at September levels. It closes the phase of monthly hikes that returned 1.65 mbd of voluntary cuts to the market.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Combined October quota totals 31.01 mbd — Saudi Arabia 10.478 mbd, Russia 9.949 mbd, Iraq 4.431 mbd, Kuwait 2.676 mbd, Kazakhstan 1.628 mbd. The group now shifts focus to reviewing 2027 production baselines before setting new quotas.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Iran-Hormuz disruption is keeping actual OPEC+ output well below paper quotas. Rystad Energy's Jorge Leon: "OPEC+ can change production targets on paper, but it cannot guarantee that those barrels will be produced or actually reach the market."
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy desks and macro traders tracking the physical oil supply gap against the group's paper targets.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Tesla (TSLA) -5.92% to $354.08 — invite-only Cybercab launch underwhelms and NHTSA opens Audit Query AQ26002 into self-certification</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Muted Austin Cybercab launch and a same-day NHTSA audit into self-certification knock TSLA back below $360.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Tesla began commercial Cybercab rides in a geofenced area around Austin on Thursday Sept 3 — the event was invite-only, wasn't livestreamed, and CEO Elon Musk did not appear. The next day NHTSA opened Audit Query AQ26002 into Tesla's self-certification of the vehicle against FMVSS.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
NHTSA is examining the process and technical data Tesla used to self-certify the Cybercab — which has no steering wheel, brake pedal, accelerator pedal, or conventional mirrors — as compliant with Federal Motor Vehicle Safety Standards. TSLA closed Friday down 5.92% at $354.08 on 64.4M shares, about 53% above its 3-month average volume.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
