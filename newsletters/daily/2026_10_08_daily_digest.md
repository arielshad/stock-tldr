<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Fed September FOMC Minutes — Unanimous 25bp Hike Confirmed; 10Y Hits 5.36%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">September FOMC minutes codify a hawkish, data-dependent Fed — unanimous hike with 'most' participants seeing another 25bp by year-end as long-end yields hit fresh 24-year highs.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Fed released the minutes of its September 15-16 policy meeting on Oct 7. The Committee raised the target range 25bp to 3.75–4.00% on a unanimous 12-0 vote — the first rate hike since 2023.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
No dissents. Most participants saw another 25bp hike "likely appropriate by year end," citing persistent energy-driven inflation and sticky core services. The 10Y yield hit ~5.36% intraday — the highest since 2002.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The minutes widen the gap between the Committee's stated path and market pricing (~20% Oct hike odds after weak +29K payrolls). Sept CPI (Oct 15) and Sept PCE (Oct 30) are now pivotal data points.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, and Fed watchers navigating the data-dependent path to year-end.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Constellation Energy (CEG) +~15% — Google Signs 20-Year PPA for 890 MW of New Nuclear Capacity</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Google backstops 890 MW of new nuclear uprates with a 20-year PPA, and separately locks in 2.7 GW of firm PJM supply for 15 years.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Google and Constellation Energy announced a long-term strategic clean-energy deal on Oct 6. Google will offtake 890 MW of new nuclear capacity via a 20-year PPA, plus a separate 15-year 2,700 MW energy supply deal — $4.3B in Constellation investment.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The 890 MW comes from modernizing turbines, steam generators, and digital controls at 11 existing Constellation reactors in IL, PA, and NJ — uprates, not new builds. First deliveries expected in 2028.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the largest commercial nuclear uprate PPA for a US hyperscaler to date. It cements the thesis that AI data-center load is turning existing nuclear fleets into long-dated infrastructure — CEG closed +~15% to ~$307.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-infra investors, power and utilities desks, and nuclear supply-chain players watching hyperscaler energy procurement.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Levi Strauss (LEVI) Q3 FY26 — Adj EPS $0.48 vs $0.36 Est, $78.6M Tariff Refund Lifts Margins, FY26 Guide Raised</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Levi's beats on tariff-refund-driven margins and raises FY26 EPS guide to $1.54-$1.56; DTC undershoots internally, stock muted in after-hours.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Levi Strauss reported fiscal Q3 2026 (ended Aug 30) after Wednesday Oct 7's close. Adj EPS of $0.48 crushed the $0.36 consensus; revenues of $1.61B rose 4% reported / 5% organic. A $78.6M IEEPA tariff refund drove 490 bps of gross-margin expansion.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Gross margin reached 66.2% (+450 bps). FY26 adj EPS guidance was raised to $1.54–$1.56 (from $1.46–$1.52) and gross-margin guide lifted to +130 bps. The quarterly dividend was raised 14% to $0.16; a $100M ASR was announced.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The headline beat is a tariff-refund story, not a demand story — the muted overnight reaction (-1.6%) confirms the market sees it the same way. Sets the template for apparel peers (LULU, GAP, PVH) sitting on similar IEEPA tailwinds.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Apparel and retail analysts, tariff-exposed consumer-discretionary PMs, and LULU/GAP/PVH holders watching DTC traffic trends.
</p>
