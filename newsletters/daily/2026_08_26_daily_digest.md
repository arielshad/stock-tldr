<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">DKS -30.67% — worst day in 3 years after Q2 miss and Foot Locker guide cut</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">DKS craters ~31% after Q2 miss and FY guide cut, dragged by newly acquired Foot Locker.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Dick's Sporting Goods reported Q2 FY26 (ended August 2) before the open Tuesday. Adjusted EPS $3.53 missed the $3.78 estimate; consolidated revenue $5.59B fell short of the $5.65B target. Management cut its FY26 outlook.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
DICK'S banner posted +4.9% comps, but newly folded Foot Locker had proforma comps of -3.6% and segment operating income was guided to a $(40)M–$(80)M loss. Full-year EPS guide was cut to $10.94–$11.94.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
It's the largest one-day drop for DKS since 2023 — roughly $5B in market cap wiped, about twice what DKS paid for Foot Locker itself. It's the first major stress test of the deal and drove sympathy weakness in NKE and ASO.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Consumer-discretionary desks tracking athletic retail and the Foot Locker integration thesis.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Wccftech report that Trump will let Apple buy CXMT DRAM and YMTC NAND after the Xi summit knocks 5–7% off the U.S. memory complex.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Weekend reporting from Wccftech says the Trump administration is prepared to sign off on Apple sourcing memory from CXMT (DRAM) and YMTC (NAND), with the announcement expected after Trump and Xi meet in the U.S. in late September. Both Chinese chipmakers are on the Pentagon's Section 1260H list and YMTC is also on the Commerce Department's Entity List.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Per the reporting, DRAM/NAND sourced from CXMT and YMTC would initially only be used in Apple products sold inside China. Lynx Equity's KC Rajkumar calls the selloff an overreaction, noting CXMT lacks iPhone qualification and YMTC has committed its newest NAND capacity to domestic customers.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
SanDisk had run 572% YTD into Friday's close and MU/WDC rode the same memory-AI bid — the tape is now pricing a real Chinese competitor gaining Apple's blessing. It also reads as a signal Washington may trade export controls for deal wins around the September summit.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Semis traders, Apple supply-chain analysts, and China policy desks tracking the U.S.–China diplomatic setup around the September summit.
</p>

<strong style="color: #f7ff00;">What is it?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Consumer Confidence August 2026 — 89.4 (7-month low); Expectations Index 68.2, deep in recession-warning territory</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Consumer confidence slips to a 7-month low as forward expectations deteriorate even while current conditions improve.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Conference Board's Consumer Confidence Index for August 2026 was released at 10am ET Tuesday. Headline dipped 0.8 points to 89.4, a seven-month low below the 90.2 consensus and prior reading.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The Present Situation Index rose 6.8 points to 121.2 on improved labor-market perceptions (jobs "plentiful" rose to 27.0% from 24.4%). But the Expectations Index — the six-months-ahead gauge — dropped 5.8 points to 68.2, well below the 80 threshold historically associated with a coming recession.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The divergence — "right now feels ok, six months looks bad" — is exactly the shape that has preceded consumer spending softening. Consumer-discretionary desks read it alongside DKS's guidance cut the same morning; both point to more caution in H2 discretionary spend.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders and consumer-discretionary desks building H2 spending outlooks.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US new-home sales July 2026 — 607K SAAR (-10.5% M/M, biggest monthly drop of 2026); supply climbs to 9.6 months</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">US new-home sales fall 10.5% in July to a 607K annualized pace — biggest monthly drop this year; unsold inventory swells to 9.6 months.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Census Bureau and HUD released July 2026 New Residential Sales data Tuesday. The SAAR came in at 607K, versus 678K in June — a 10.5% month-over-month decline and 6.3% below the July 2025 rate.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The median sales price fell to $393.8K (-2.3% M/M) as builders cut price to keep contracts alive. Unsold new-home inventory stood at 488K = 9.6 months of supply (well above the ~6-month "balanced" benchmark). Average price rose to $508.8K (+4.1% M/M), pointing to a mix-shift toward larger homes among what did sell.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Builders are squeezed at both ends: sales pace decelerating and supply rising. Combined with slower Case-Shiller prints, the housing market is quietly cooling. Watch LEN, DHI, TOL, PHM, KBH and building-products names (BLD, IBP) into fall.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Housing analysts and rates strategists tracking the builder squeeze and H2 housing demand.
</p>
