<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

<strong style="color: #f7ff00;">Why does it matter?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

ETH, XRP, and SOL each dropped 3–4%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Spot Bitcoin ETFs had already shed ~$635.5M Thursday Oct 22 (IBIT -$254M, FBTC -$218M) and ~$137.9M Friday Oct 23, totaling ~$773M in two days — removing the institutional bid before the weekend geopolitical headline hit. 24h crypto liquidations ran ~$727.8M across ~196K traders, with longs accounting for 94% of the washout.

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is a textbook leverage flush: a weekend geopolitical headline forces margin out of a 24/7 market unavailable to ETF traders. The ~$773M two-day ETF outflow is the clearest signal that institutional demand that drove September's rally has stepped back ahead of the Oct 28 FOMC and an ~$11B BTC options expiry.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">SpaceX in talks for ≥80K US cell sites to build a fourth nationwide carrier</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Bloomberg scoop; Crown Castle (CCI) +~12% to ~$87, American Tower (AMT) +~7%; AT&T -~5%, Verizon -~3%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Bloomberg reported Thursday after close that SpaceX is negotiating with Crown Castle, American Tower, and Vertical Bridge to lease space on at least 80,000 US cell sites — a move that would complement Starlink's direct-to-cell satellite network and put SpaceX on the path to becoming a fourth nationwide wireless carrier.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
SpaceX already has FCC approval for ~15,000 Starlink satellites built for direct-to-smartphone connectivity and recently closed an ~$8B nationwide 800 MHz low-band spectrum purchase from Grain Management. Bloomberg says deal scope could run into the billions. Crown Castle CEO Dan Schlanger, asked about SpaceX on the Wednesday earnings call, said: "You can assume that we're talking to all parties."
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
If SpaceX leases ground-based cell sites at scale, it changes the structural setup of US wireless: a brand-new, non-carrier tower tenant for REITs (CCI, AMT, SBAC) and the first credible fourth-carrier threat since the Sprint/T-Mobile merger. Bernstein's Laurent Yoon called an 80K-site lease commitment "a point of no return."
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Telecom analysts, tower REIT holders, Starlink watchers.
</p>
