<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Amazon crosses $200B in a single quarter for the first time as AWS accelerates to 37% growth and operating income jumps 43%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Amazon reported Q2 2026 results after the bell on Thursday July 30. Revenue hit $200.6B (+20% Y/Y) — the first $200B+ quarter in company history — and operating income of $27.5B (+43% Y/Y) blew past guidance, while diluted EPS came in at $5.75 vs $1.82 consensus.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
AWS delivered $42.2B in revenue (+36.7% Y/Y), the fastest growth rate in 18 quarters, at a 39.4% operating margin. Advertising revenue grew 26% Y/Y to $19.8B; Q3 guidance calls for $197-202B in net sales and $22.5-26.5B in operating income.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
AWS at 37% growth validates that hyperscaler AI demand is real and translating to cloud revenue — a direct read-through for MSFT Azure (+43% cc) and GOOGL Cloud (+82%). The 43% jump in operating income against $60B+ in trailing capex intensity is the datapoint AI-skeptics needed.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-capex traders, cloud sell-side, mega-cap allocators.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Q2 US GDP advance +1.5% vs +2.1% est — private-demand core rips to +3.9% while government spending drops and prices heat up.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BEA released the Q2 2026 GDP advance estimate on July 30 at 8:30am ET. Real GDP grew at a 1.5% annualized pace, below the 2.1% consensus and the 2.1% posted in Q1 2026.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Real final sales to private domestic purchasers — the BEA's cleanest read on underlying demand — accelerated to +3.9% (from +1.7% in Q1). But the headline PCE price index rose to +5.1% (from +4.6%), while core PCE eased to +3.4% (from +4.4%).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The headline miss lands one day after the FOMC held at 3.50–3.75% on a 9-3 hawkish-dissent vote. Private-demand acceleration argues the consumer/investment engine is still running, but PCE re-acceleration (+5.1%) keeps supply-side inflation pressure alive amid ongoing tariffs and geopolitical risk.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US June 2026 PCE — Headline +3.7% (from +4.1%), Core +3.3% for 4th Straight Month</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Fed's preferred inflation gauge cools sharply on the headline in June — but core PCE stays sticky at 3.3%, extending the longest above-3.3% run since 2023.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BEA published the June 2026 Personal Income and Outlays report on July 30. Headline PCE fell 0.1% M/M and dropped to +3.7% Y/Y (from +4.1% in May), the biggest monthly drop in some time, while core PCE — the Fed's preferred gauge — eased to +3.3% Y/Y (from +3.4% in May).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Core PCE at +3.3% has now been at or above that level for four straight months — the longest such streak since fall 2023. The report lands the day after the FOMC held rates at 3.50–3.75% on a 9-3 hawkish-dissent vote, with three members (Hammack, Kashkari, Logan) pushing for a 25bp hike.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The 40bp drop in headline gives the Fed's doves a talking point, but sticky core keeps the hawks' case alive — the setup that produced Wednesday's 3-dissent hold. Markets now look to August 1 nonfarm payrolls and the August 26 PCE release as the next inflection points on the September FOMC path.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, Fed watchers.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">NYSE-parent ICE buys electronic bond-trading leader MarketAxess for $6B all-cash at 33% premium — a fixed-income consolidation play.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

Both boards unanimously approved; close expected H1 2027 pending regulatory clearance.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The $167/sh price is a 33% premium to MKTX's July 29 close, at ~10.6x LTM EBITDA with $100M of targeted annual cost synergies within three years. ICE will finance the acquisition entirely with newly issued debt and expects adjusted EPS accretion in the first full year post-close.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This bolts one of the largest electronic corporate-bond venues onto ICE's fixed-income data + indices + post-trade complex, positioning ICE against Tradeweb and Bloomberg's fixed-income venues. For MKTX holders it's a clean exit at premium after two years of decelerating share gains against Tradeweb.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Fixed-income desks, exchange-sector equity holders.
