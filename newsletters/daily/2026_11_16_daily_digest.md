<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Jensen Huang steps down as Nvidia CEO; CFO Colette Kress named interim leader while board searches for permanent successor.</p>

<strong style="color: #f7ff00;">What is it?</strong><br>
Nvidia's board announced Thursday that Jensen Huang has resigned as president, CEO and member of the board, effective immediately. CFO Colette Kress takes over as interim CEO while director Harvey C. Jones becomes the company's first-ever chair of the board.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>

<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

China macro traders, EM allocators, global commodity desks tracking iron ore and copper.

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">October producer prices cool from September's shock but the 12-month rate climbs to 6.5% — highest since Nov 2022 — hardening the Fed's case for a December rate hike.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Goods prices surged +10.2% Y/Y — the largest since October 2022 — driven by food +1.3% M/M. Services rose +0.2% M/M for a fifth straight gain, led by transportation and warehousing (+2.0%). Core Y/Y hit +4.9%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
CME FedWatch now prices ~89% odds of a 25bp hike at the December 8–9 FOMC (target to 4.00–4.25%), with Capital Economics seeing consecutive Dec + Jan hikes as most likely. Short-dated Treasuries sold off; S&P 500 fell ~0.5–0.6% and Nasdaq ~0.95%.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, and Fed watchers positioning ahead of the December 8–9 FOMC.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Nubank (NU) Q3 2026 — Record $1.1B Net Income (+31% Y/Y), 32% ROE, 143M Customers; Stock +11.71%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Nubank cleared $1.1B of quarterly profit and crossed 143M customers in Q3 2026 — stock popped 11.7% the next session.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Nu Holdings (NYSE: NU) reported Q3 2026 after the close Wednesday Nov 12. Gross revenue reached a record $6.3B (+37% Y/Y FX-neutral) and net income hit a record $1.1B (+31% Y/Y), extending the first-ever $1B+ quarter from Q2.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Annualized ROE reached 32% with net interest margin at 22.5%. The customer base grew to 143M (+3.7M Q/Q) across Brazil (~120M), Mexico (16.6M), and Colombia (6.1M). The credit portfolio grew to $41.6B (+33% Y/Y), with 90-day NPL ticking up to 7.3%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Nubank is now one of the most profitable large banks in LatAm by ROE — the second straight $1B+ profit quarter confirms the Q2 inflection wasn't a one-off. The rising NPL rate (7.3%) frames the next key question: can originations stay ahead of losses as the Brazilian consumer cycle tightens.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
LatAm equities desks, fintech/neobank specialists, and EM financial-services investors — Berkshire Hathaway remains a holder from the pre-IPO round.
</p>
