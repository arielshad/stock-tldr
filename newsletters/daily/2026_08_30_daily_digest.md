<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Warsh's Jackson Hole debut: inflation still too high, forward guidance out — 2Y yield +8bp to 4.31%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Warsh's Jackson Hole debut leans hawkish — inflation still 'above our 2 percent target', forward guidance 'has overstayed its welcome', and the 2Y yield jumps ~8bp to 4.31%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Federal Reserve Chair Kevin Warsh delivered his first Jackson Hole keynote — titled 'In Our Time' — on Friday Aug 28 at the Kansas City Fed's annual economic policy symposium, marking his 100th day at the helm.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Warsh declared inflation is 'above our 2 percent target' and summer readings 'do not tell me that underlying trends have meaningfully improved.' He also said forward guidance 'has overstayed its welcome,' signaling a return to data-dependent policy over predetermined commitments.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Bond markets read it as hawkish: the 2Y note jumped ~8bp to 4.31% (highest since late July), while equities gave back gains — S&amp;P -0.25% to 7,711.76, Nasdaq -0.52% — though all three indices still finished higher on the week. Next catalysts: August jobs (Sep 5), CPI (mid-Sep), FOMC (Sep 16–17).
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, front-end rates desks, and FX participants monitoring the Fed rate path.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">PayPal (PYPL) -12.71% as Advent + Stripe walk from $53B LBO — board rejected $60.50/share bid</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">One of the biggest-ever LBOs falls apart as Advent + Stripe walk away from a $53B PayPal takeout that PYPL's board wanted priced higher.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Bloomberg reported Friday Aug 28 that the Advent International + Stripe consortium has abandoned its $53B pursuit of PayPal after the board rejected the $60.50/share bid as inadequate — the group is no longer pursuing a deal.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
PayPal's board rejected the initial offer and negotiations failed to produce a materially higher bid — the consortium walked rather than pay up, unwinding the 40%+ takeover premium that had built into PYPL during Q2 when market cap reached ~$52.6B.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
PYPL fell as much as 16% premarket and closed -12.71% to $53.66 — roughly $6-7 below the withdrawn bid. The failed deal removes the largest listed-fintech LBO overhang and signals where mega-buyout valuations top out even for depressed-multiple names under activist pressure.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Fintech, event-driven, and merger-arb desks; private-equity LBO watchers.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">NVIDIA (NVDA) -4.57% to $217.55 — pauses $36B AI Compute Partnership on antitrust worries</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Nvidia pauses the $36B AI Compute Partnership after antitrust worries and pushback on a customer-approval clause; stock -4.6% to $217.55.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Wall Street Journal reported Friday Aug 28 that Nvidia has paused the AI Compute Partnership, the revenue-sharing financing program launched in July to help smaller cloud providers (neoclouds) buy Nvidia GPUs.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Under the program Nvidia set a baseline hourly rate and took 50% of above-cost revenue, committing to lease capacity itself if neoclouds couldn't place it; a quarterly filing pegged total commitments at ~$36B. Two frictions killed it: employees flagged antitrust exposure, and cloud providers pushed back on a clause letting Nvidia approve which end-customers could rent capacity.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
NVDA closed -4.57% to $217.55, erasing roughly a third of the post-earnings rally from earlier in the week and reopening the 'circular financing' debate that weighed on chip names in late July.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-infra investors, chip traders, and neocloud watchers.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Chicago wheat hits 3-year high — Sep '26 closes $7.67 (+3.27%), +12.1% on the week as Russia escalates Black Sea strikes</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Chicago wheat rockets to a 3-year high as Russia signals renewed Black Sea strikes and Novorossiysk shipping stalls.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Chicago Board of Trade wheat futures posted a fresh 3-year high on Friday Aug 28 — Sep contract closed $7.67 (+3.27%), Dec settled $7.84 (+3.1%) after touching $7.9025 intraday, the highest since Feb 14, 2023.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Weekly gain was +12.1%, the largest since March 2022, driven by Russia signaling renewed attacks on Ukrainian grain infrastructure after peace-talk collapse; a major shipping line suspended service to Novorossiysk, and SovEcon trimmed Russia's August export estimate ~300K MT to 1.9M MT.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Russia and Ukraine supply more than a quarter of global wheat exports — sustained Black Sea disruption pushes food-inflation risk back into frame just as Warsh's hawkish Jackson Hole speech repriced rates; wheat is now +54.5% YTD and corn +21.8%, lifting import bills for EM buyers already rerouting to Australia and Argentina.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Ag desks, food-inflation macro traders, and EM sovereign credit analysts.
</p>
