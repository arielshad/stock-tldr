<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">FICO -26.5% to $617.87 — FHFA Ends VantageScore Mortgage Penalty</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">A single tweet from the FHFA ended FICO's exclusive hold on GSE mortgage underwriting — the stock lost roughly a quarter of its value in one session.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
FHFA Director Bill Pulte announced Fannie Mae and Freddie Mac — backing ~70% of US mortgages — will move to a single LLPA pricing grid with VantageScore 4.0 joining FICO Classic. FICO closed -26.5% at $617.87 from a $840.89 prior close.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The unified grid removes VantageScore's prior 20-point downward adjustment, so lenders can now route to either score with no pricing penalty. Rocket Mortgage CEO Jay Bray immediately named VantageScore its preferred model.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
FICO's mortgage business runs on per-pull origination fees — pricing-grid parity directly threatens that fee stream across the majority of US originations. The stock extended losses another -4.11% to $592.47 on Sept 30, now more than 70% below its $1,998 52-week high.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Financials and fintech traders, mortgage-rate watchers, regulatory-arbitrage desks.
</p>
