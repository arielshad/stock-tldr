<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US September Jobs Report — NFP +29K vs +84K est, Fed Oct hike odds collapse to ~20%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">September payrolls crater to +29K vs +84K est, July revised to -10K — Fed October hike bets collapse.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
BLS released the September 2026 Employment Situation on Fri Oct 2: nonfarm payrolls rose just 29K vs the 84K Dow Jones consensus, unemployment ticked up to 4.2% from 4.1%, and average hourly earnings slowed to +3.0% Y/Y — the softest since May 2021.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
July was revised from +21K to -10K (now negative) and August from +162K to +133K, lowering combined employment by 60K vs prior prints. Health care led with +17K; professional/business services shed 9K.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
October Fed hike odds collapsed to ~20% from ~64% a week ago. Equities rallied — Nasdaq +1.23% to 27,201 and S&P 500 +0.75% to 7,723 — on the dovish repricing that put the hawkish FOMC path squarely in doubt.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, and Fed watchers tracking the path to the next FOMC decision.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">G7 + Partners Release 100M Barrels of Oil &amp; Diesel — Brent -1.5% to $100.80, WTI -2.7% to $90.40</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">G7 taps 100M barrels of emergency oil + diesel to blunt the Hormuz-war fuel shock.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
G7 members and partners agreed Fri Oct 2 to release up to 100M barrels of oil and diesel from strategic stocks over four months, coordinated through the IEA with a frontloaded diesel component in the first 20 days.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The decision followed a virtual meeting chaired by French President Macron, with Treasury Secretary Bessent and President Trump pressing Europe to tap diesel stockpiles. IEA's Fatih Birol described it as a continuation of the 400M-barrel commitment from March 2026, of which two-thirds had already been drawn.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Brent fell 1.48% to $100.80 and WTI dropped 2.66% to $90.40 on the headline. US diesel hit $6.52/gal on Sep 22 (a record) with inventories at 107.9M bbl — a record low — but Goldman Sachs estimates the release offsets only about half of the Hormuz-driven diesel surge.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy desks, macro traders, and airline + trucking analysts watching the diesel crack and Hormuz newsflow.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">OPEC+ Seven roll over September output levels for November, extending the pause that started last month.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
On Sun Oct 4, the 68th JMMC of OPEC+'s seven core members (Saudi Arabia, Russia, Iraq, Kuwait, Kazakhstan, Algeria, Oman) met online and decided to maintain September 2026 production levels for November — the second straight monthly pause after completing the April–September increase series.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Combined November quotas remain near 31 mbd. The group completed unwinding its 1.65 mbd voluntary cut tranche in September; a separate 2 mbd 2022 cut stays through year-end. Next JMMC review is Nov 1, 2026.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Real Gulf exports are running 60–80% of normal since the U.S.-Israel-Iran war closed Hormuz on Feb 28. With Brent still above $100 post-G7 release, the rollover confirms there is no OPEC+ supply cushion coming — the oil complex (XLE, XOM, CVX) stays tied to Hormuz newsflow.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy traders, refiners, and macro desks watching the Hormuz–OPEC supply dynamic through Q4.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">onsemi Amends Synaptics Deal to $5.7B All-Cash at $123/Share — SYNA +14%, ON +5%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">onsemi flips the Synaptics deal to all-cash at $123/share, $5.7B — SYNA jumps ~14%, ON jumps ~5%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
onsemi (ON) and Synaptics (SYNA) filed an Amended and Restated Merger Agreement Thu Oct 1 after close: ON will acquire SYNA for $123/share in cash (~$5.7B), replacing the June 25 all-stock structure (1.350 ON shares per SYNA share, ~$7B at signing).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The amendment follows an unsolicited bid SYNA received Sept 2 from a strategic party. Financing is ON cash plus a $2.45B committed term loan from Morgan Stanley. U.S. antitrust clearance is already in hand; closing targets mid-2027 subject to SYNA shareholder approval.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The original stock deal cratered ON -23.66% on June 26. The all-cash restructuring removes the dilution overhang and is now immediately accretive to ON's non-GAAP EPS; SYNA holders get a fixed cash price instead of ON shares that had been trading well below the original ratio's implied value.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Semis M&amp;A desks and SYNA/ON holders tracking the proxy filing and mid-2027 close timeline.
</p>
