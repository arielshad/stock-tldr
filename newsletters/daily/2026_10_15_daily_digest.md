<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US September CPI +3.7% Y/Y — gasoline rips, core holds</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Headline CPI jumps to +3.7% Y/Y as gasoline rips +9.1% M/M — but core holds at +0.3% M/M / +2.6% Y/Y, and the 10Y yield actually eases 3bp to 5.19%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BLS September 2026 CPI came in above consensus: headline +0.6% M/M / +3.7% Y/Y vs +0.3% / +3.6% est — the hottest monthly print since early 2026. Core (ex food and energy) held at +0.3% M/M / +2.6% Y/Y.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Gasoline +9.1% M/M (+34.2% Y/Y) accounted for over half the monthly all-items increase; overall energy +5.2% M/M. Shelter +0.4% M/M, food flat.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Despite the headline overshoot, bond desks read it as an energy-driven miss — core pace was unchanged from August — so the 10Y yield fell 3bp to 5.19%. The <a href="https://finance.yahoo.com/quote/%5EGSPC" style="color: #f7ff00;">S&amp;P 500</a> shed 1.11% to 7,718.94 on the combined CPI print and mixed bank-earnings tape.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, and FOMC watchers ahead of the next decision.
</p>

An explicit "supply &lt; demand" signal through 2028 re-anchors the AI build-out thesis after the Oct 8 chip rout. Positive read-across for <a href="https://finance.yahoo.com/quote/TSM/" style="color: #f7ff00;">TSM</a>, <a href="https://finance.yahoo.com/quote/AMAT/" style="color: #f7ff00;">AMAT</a>, <a href="https://finance.yahoo.com/quote/LRCX/" style="color: #f7ff00;">LRCX</a>, and <a href="https://finance.yahoo.com/quote/KLAC/" style="color: #f7ff00;">KLAC</a>.
