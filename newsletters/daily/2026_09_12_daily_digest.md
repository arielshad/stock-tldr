<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Second hike confirms the ECB is "in tightening mode," setting up a global rate-hike wave: BoJ at 1.00%, ECB at 2.50%, and the Fed 90% priced for a hike next week. Euro area 2-year swap +~15bp; curve flattens.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Global macro traders, EUR crosses, and European bank equity desks.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Saudi August Crude Output Hits 6.238 mbd — Lowest Since 1990; Brent Settles at $105</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Saudi August production plunges 1.9 mbd MoM to 6.238 mbd — lowest since 1990 — as US–Iran war chokes export routes; Brent settles $105.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Saudi Arabia notified OPEC that its August 2026 crude output fell 1.9 million barrels per day to 6.238 mbd — its lowest since 1990, before the first Gulf War. Exports fell to ~3.1 mbd, the weakest since at least 2013, as the kingdom cited renewed US–Iran hostilities and continuing Houthi strikes on Red Sea shipping.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The drop is real, not policy — OPEC+ held quotas at September levels on Sept 6 and Riyadh's official target sits well above 6.2 mbd. On Thursday Sept 10, Brent settled +3.90% at $105.16 and WTI +4.31% at $100.16, pushing the US 10-year yield to 4.902%, the highest close since October 2023.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
A physical supply loss of ~1.9 mbd from the world's largest swing producer is a structural shock — spare-capacity math gets very tight into Q4 with the SPR at multi-decade lows. Reads through to XLE/OIH/refiners long, transportation and rate-sensitives short. Rate rip on the long end sets a hostile backdrop for equities into next week's FOMC.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy desks, macro traders, and rates-focused allocators.
</p>
