<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">10Y Treasury tops 5.22% intraday — 19-year high — as NY Fed's Williams calls another 2026 hike "reasonable"</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Williams pivots from "wait and see" to "reasonable to hike again this year" — October hike odds jump to 77.5% from 53%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
NY Fed President John Williams told the London Macro Policy Forum that investor pricing implying another rate hike this year "seems to me a reasonable way of thinking about it," marking a hawkish pivot from his September 2 "wait and see" framing.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The 10Y Treasury yield spiked to 5.225% intraday — the highest since July 2007 — before settling near 5.15%; the MOVE index hit 104, its highest since March, and October 28 hike odds jumped to 77.5% from 53%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Williams is a permanent FOMC voter and typically the number-two Fed voice — his pivot removes a key dovish anchor and validates the September-October rate repricing that has moved yields ~50bp in three weeks.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Rates traders, equity desks, and macro portfolio managers tracking the Fed's terminal-rate path.

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">State visit ends with a narrow tariff carve-out, a formal AI incident channel, and a coal offtake — not a sweeping trade deal.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
President Trump hosted President Xi at the White House on September 25 for a formal state-visit summit, with deliverables disclosed in a White House fact sheet the same day and confirmed by Beijing's foreign ministry on September 26.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The US-China Board of Trade recommended favorable tariff treatment on $30B of non-sensitive goods each way; China committed to ≥10M metric tons of US coal per year in 2027-2028; and leaders launched a bilateral "Super Intelligence" dialogue with the next exchange due by November 2026.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The tariff carve-out covers specific SKUs, not headline reciprocal rates, so the S&P reacted modestly (+0.51%); the bigger forward signal is the formal AI incident channel, which both governments now endorse ahead of a November follow-through.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, tariff-exposed industrials, coal miners, and ag exporters with direct read-through from the listed goods categories.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">UMich September final consumer sentiment 48.1 — 4-month low, -7% MoM; year-ahead inflation expectations jump to 4.6% from 4.0%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">UMich September final: sentiment slides to a 4-month low as year-ahead inflation expectations jump to 4.6%.</p>

<strong style="color: #f7ff00;">What is it?</strong><br>
The University of Michigan's final September 2026 consumer sentiment reading came in at 48.1, down from 51.7 in August — a 7.0% monthly decline and the weakest print in four months, released on the same Friday morning the 10Y yield sat near 5.18%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>

</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

Macro traders and rates desks watching the Fed's data-dependent path into the October 28 FOMC meeting.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Nike (NKE) -0.67% to $35.75 — BofA's Hutchinson cuts to Underperform, $30 PT (from $47); FY27 EPS -11% ahead of Oct 1 print</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">BofA rips Nike PT to $30, tags it Underperform ahead of Oct 1 earnings — dividend flagged as at-risk on cut EPS.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Bank of America analyst Lorraine Hutchinson cut Nike from Neutral to Underperform on September 25, dropping her price target to $30 from $47 — roughly 17% below Nike's $35.75 close — six trading days before Q1 fiscal-2027 earnings.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Hutchinson cut her FY27 EPS estimate 11% to $1.43 (~14% below consensus) and FY28 estimate 12% to $1.87, citing a longer-than-expected turnaround, weak North America wholesale momentum, and continued sales pressure in Greater China; the $1.64 annual dividend now exceeds her FY27 EPS estimate.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Nike is the largest holding in most large-cap apparel and consumer-discretionary baskets, so a Street Underperform + $30 tape sets the earnings bar; peers moved on the read-through: Lululemon -0.34%, Under Armour -1.56%.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Consumer-discretionary desks and dividend investors watching whether the October 1 print resets FY27 guidance far enough to protect the payout.
