<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">S&amp;P 500 and Dow enter correction on a 7th straight down day as the AI trade cracks.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
U.S. stocks closed sharply lower Friday, with the S&amp;P 500 (-3.70% to 6,910.39) and Dow (-1.93% to 48,147.33) entering technical correction on a seventh consecutive losing session. The Nasdaq Composite fell 5.28% to 22,617.73, turning negative year-to-date for 2026.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The AI/chip complex cracked on Nvidia's CEO exit and a Reuters report of an SEC civil probe into Nvidia disclosures; Anthropic (ANT) fell 8.5% in its second session, taking further wind out of the AI trade. Defensives (WMT, COST, JNJ, PG) outperformed ~+1%, a classic risk-off rotation.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Index traders, AI/semi investors, macro desks watching the VIX and next catalysts: FOMC Dec 8–9, CrowdStrike Dec 1, Zscaler Dec 2.

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Largest IPO in history: Anthropic opens 34% above its $83 price, briefly pushing market cap above $2T before fading.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Anthropic (ANT), maker of the Claude AI models, began trading on Nasdaq Thursday Nov 19, opening at $111.50 — 34% above the $83 IPO price — with proceeds of $81.3B from 980M Class A shares making it the largest IPO in history, surpassing SpaceX's $75B June 2026 debut.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Shares hit an intraday high of $114.99 (briefly ~$2.0T implied market cap) before fading to $97.17 by the close (+17.1% vs offer); tech giants Nvidia, Microsoft, Google, Broadcom, and AMD bought ~$26B at the IPO price, taking total fundraising to ~$107B with the greenshoe.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The debut cements AI as the dominant 2026 IPO theme and reprices the private AI market at mega-cap-tech scale. Nasdaq-100 inclusion is slated for Dec 18; S&amp;P 500 eligibility is at least a year away.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI investors, IPO allocators, and growth equity — the public float is only ~7.4% of total shares, making this a thin but highly watched market.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Bloomberg says CrowdStrike is in talks to buy Zscaler — which would be its largest deal by a wide margin. Treat as rumor until confirmed.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
No price has been reported; Zscaler's market cap was ~$32B at Friday's close vs CrowdStrike's ~$235B. Sources told Bloomberg a deal could "come together soon" but could still fall through. Both companies report earnings in early December (CRWD Dec 1, ZS Dec 2).

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Intuit Beats Q1 FY27, Sells Mailchimp for $3.68B — Cuts FY27 Guide on Credit Karma; INTU -12.8%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Intuit beats Q1, agrees to sell Mailchimp to Bending Spoons for $3.68B, but cuts FY27 revenue guide on Credit Karma weakness.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Intuit posted fiscal Q1 2027 (quarter ended Oct 31) results Wednesday Nov 19, beating on revenue ($4.354B, +12%) and non-GAAP EPS ($2.91, +56%), while announcing it will sell Mailchimp to Italy's Bending Spoons for ~$3.68B. The stock fell ~12.8% Friday on a cut to full-year revenue guidance.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The Mailchimp sale is $3.31B cash + $368M in Bending Spoons stock, closing early 2027; Intuit will use the cash for additional FY27 buybacks. Updated FY27 revenue guidance was trimmed to $23.081–$23.365B (+8–9%), with Credit Karma now seen growing only 3–7%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Intuit paid ~$12B for Mailchimp in 2021 and is now selling at $3.68B — a stark implied write-down on that acquisition. The Credit Karma guide cut signals that higher rates and AI-driven disruption to financial search are pressuring lead-gen fintech across the board.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Fintech and software investors — the Credit Karma read-across affects NerdWallet (NRDS) and others dependent on rate-sensitive financial lead generation.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">BJ's Wholesale Crushes Q3 — EPS $1.73 vs $1.23 Est, Raises FY26 Guide on Digital &amp; Member Momentum</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">BJ's clears the quarter at $6.15B, lifts the full-year bar on member and digital momentum.</p>

<strong style="color: #f7ff00;">What is it?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
