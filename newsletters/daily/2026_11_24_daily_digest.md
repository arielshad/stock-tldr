<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">NVIDIA reinstates Jensen Huang as CEO — NVDA +31.48%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">NVIDIA board unanimously reinstates Jensen Huang as CEO 11 days after his resignation; NVDA closes +31.48% in the largest single-day move for a mega-cap this year.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
NVIDIA's board unanimously voted on Nov 22 to reinstate co-founder Jensen Huang as President, CEO, and board director, effective immediately. Interim CEO Colette Kress returns to CFO-only; Harvey C. Jones remains Chair.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The board received input from senior U.S. government officials and concluded Huang's return "poses no national security risk." An independent-director investigation into a foreign-intelligence targeting report will continue to completion alongside a new National Security and Export Control Committee.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
NVDA closed +31.48% at $165.05 — a ~$1T intraday market-cap swing — and dragged the AI complex higher: MU +19%, DELL +20.5%, CRWV +22.3%, LITE +18.2%. The ongoing SEC civil probe remains open.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Semis desks, mega-cap tech PMs, event-driven and governance funds.
