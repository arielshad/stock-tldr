<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Anthropic (ANT) prices IPO at $83 — $81.3B raised, $1.5T valuation, largest US IPO ever</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Anthropic priced the largest US IPO ever at $83/share — ~$81.3B raised, $1.5T valuation; trading begins Thursday on Nasdaq as ANT.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Anthropic PBC, the AI lab behind Claude, set a final IPO price of $83 per Class A share — above the $70–$78 range — on 980M shares (up from 825M), as the book ran heavily oversubscribed.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
At $83/share the deal raises ~$81.3B, topping SpaceX's $75B as the largest US IPO on record, with implied fully-diluted valuation near $1.5T. AMD, Broadcom, Google, Micron, Microsoft, Nvidia and TSMC Partners also bought $26B of non-voting shares in a concurrent private placement.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
ANT is now the first mega AI-lab listing and an index-weight event for Nasdaq-100 inclusion. First-trade levels today will set the post-money benchmark for the entire private AI market and test whether public investors will fund the capex arms race at $1.5T.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro/AI trade, IPO desks, mega-cap allocators watching NVDA, GOOGL, MSFT, AMD and AVGO.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Nvidia's Q3 FY27 revenue doubled to $115.8B, beating consensus by ~$6.7B; Q4 guide of $130B ± 3% tops the ~$125.1B estimate. First print since Jensen Huang resigned Nov 12.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Nvidia reported Q3 FY27 results on November 17, the first earnings release since CEO Jensen Huang's resignation on Nov 12. Interim CEO Colette Kress ran the call; board chair Harvey Jones confirmed Huang will not return.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Revenue of $115.8B rose 103% Y/Y and 20% Q/Q, with Data Center contributing $107.6B (+110%). Non-GAAP EPS was $2.68 vs ~$2.48 estimate. Q4 FY27 guide of $130.0B ± 3% beat the ~$125.1B consensus; $28.1B was returned to shareholders in Q3.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Doubling revenue off a $57B base proves the AI-compute arms race is still accelerating. The Q4 guide beats Street by ~$5B even after ex-China DC compute exclusions, and the ~$227B remaining buyback authorization signals management confidence at current multiples.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI/semis investors, data-center allocators, anyone watching AMD and AVGO as compute comps.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">UNH -10.2%, HUM -13% on CMS CRUSH anti-fraud rule — $90B in projected 10-yr savings</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">CMS's proposed CRUSH rule extends Medicare Advantage audit extrapolation back to 2018; UNH -10%, HUM -13% as managed-care re-rates lower.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
CMS issued proposed rule CMS-6098-P (the CRUSH rule) on Nov 16, reinstating statistical extrapolation across Medicare Advantage RADV audits starting with payment year 2018 and projecting ~$9B in recoveries per audit year industry-wide.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
CMS samples MA charts, extrapolates the error rate across the full contract, and claws back overpayments. UNH closed at $349.91 (-10.21%) on 17.4M shares (~3× avg); HUM fell ~13%; ELV -6.13%; CVS -3.48%; CI -2.75%. Public comment closes Jan 19 2027.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The biggest regulatory shock to managed care since the 2023 RADV rule. Back-dating extrapolation to 2018 opens ~a decade of retroactive audit exposure, sitting directly on top of the 2027 MA bid cycle.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Managed-care analysts, healthcare sector funds, DC-policy traders watching UNH, HUM, ELV, CVS and CI.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Oct FOMC minutes: 'almost all' participants see more hikes under baseline, some open to a &gt;25bp move at the Dec meeting; AI-demand inflation called out explicitly.</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">UK October CPI +3.6% Y/Y — 1-year high; core 2.8%, services 3.7%; BoE Dec 18 MPC in focus</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">UK CPI edges up to 3.6% in October, a one-year high, just below the BoE's 3.7% forecast ahead of the December MPC.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The ONS published the October 2026 CPI bulletin at 07:00 GMT on Nov 18. Headline inflation printed +3.6% Y/Y, up from 3.5% in September — the highest in a year.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
CPI rose +0.5% M/M. Core CPI held at +2.8% Y/Y and services at +3.7%. Goods CPI jumped to +3.5%, the highest since Sep 2023. Motor fuels and the Oct 1 tobacco duty hike were the main upward drivers; restaurants and hotels partially offset.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The print lands just below BoE's 3.7% projection with core and services both sticky, making a near-term cut harder to argue into the Dec 18 MPC. GBP, Gilts and FTSE financials are the primary reactors.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
UK rates and FX desks, Gilt traders watching the BoE Dec 18 MPC decision.
</p>
