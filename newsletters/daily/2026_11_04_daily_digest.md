<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Apple's September quarter sets records in revenue, iPhone and EPS, but a soft December-quarter gross-margin outlook sends shares ~-2.8% after hours.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Apple reported fiscal Q4 2026 after the close on Monday November 2 — the company's first earnings call under new CEO John Ternus, who succeeded Tim Cook on September 1. Revenue of $114.5B (+12% Y/Y) and diluted EPS of $2.10 (+14%) both set September-quarter records.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
iPhone $57.58B (September-quarter record), Services $31.57B (all-time high), gross margin 47.9% including ~1pp from tariff refunds. Apple returned ~$28B to shareholders and declared a $0.27/share dividend payable Nov 16.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Double-digit iPhone growth and Services hitting an all-time high are the key positives, but a cautious Q1 gross-margin bridge drove an after-hours decline of ~-2.8%. The iPad miss and India/supply-chain commentary are the swing factors for whether the AAPL multiple holds.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Mega-cap holders, consumer-tech desks, and index desks watching the holiday quarter setup.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Marvell (MRVL) to acquire Lumentum (LITE) in $115B all-stock AI-connectivity megamerger — MRVL -12.7%, LITE -18.6%, SOX -3.37%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Marvell to buy Lumentum in an all-stock AI-connectivity megadeal at ~$115B implied EV — but both stocks tank as the Street balks at dilution, antitrust risk, and a 2028 close.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Marvell Technology and Lumentum Holdings announced a definitive all-stock merger to form a vertically integrated AI connectivity platform. The deal implies an enterprise value of about $115B for Lumentum — roughly $1,132 per LITE share, a 23.9% premium over each company's unaffected Oct 28 closing price.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Fixed exchange ratio: 4.500 MRVL per LITE share; Marvell holders would own ~67% and Lumentum ~33% post-close. The deal cites >$1B annual run-rate cost synergies and non-GAAP EPS accretion in year 1, with close targeted 1H calendar 2028 pending shareholder and regulatory approvals.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
MRVL closed -12.72% at $171.41 and LITE -18.59% at $684.40 as the market priced heavy dilution (~33% share issuance), a wide arb spread, and a 1H 2028 close timeline. The Philadelphia Semiconductor Index (SOX) fell 3.37%; antitrust review in the US and China is the single biggest open question.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Semis desks, M&amp;A arb traders, and AI-infrastructure allocators watching vertical integration in optical interconnect.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">AMD rips through Q3 with Data Center revenue nearly doubling Y/Y and a Q4 guide that implies ~66% growth on AI chip ramp.</p>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
After the Nov 2 SOX rout on the MRVL/LITE deal, AMD's +97% Data Center print and Q4 guide 4% above consensus reopens the 'AI capex still accelerating' narrative. Stock rose ~6.5% AH after closing +3.65% at $483.90.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Binance $6.3B hack — largest crypto theft ever; FBI blames North Korea's TraderTraitor; 90% of funds replaced from SAFU</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Binance says a $6.3B hot-wallet exploit — the largest crypto theft ever — is 90% backed from company funds, with the FBI pointing to North Korea.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
On Thu Oct 29, Binance disclosed a security incident that drained ~$6.3B of client token assets from its hot wallets. The exchange suspended withdrawals while the breach was triaged; by Saturday the FBI publicly named TraderTraitor — a North Korean state-sponsored unit — as the attacker, converting stolen assets into ETH for laundering.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Binance earmarked ~$6.34B of corporate funds (SAFU + Futures Insurance Fund + treasury) to replace stolen tokens; ~$3B was frozen on-chain via Tether ($1.567B USDT), Circle ($800M+ USDC), Ripple (RLUSD) and others. By Saturday 90% of stolen value was replaced, with withdrawals targeting a Nov 1 resumption.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Bitcoin fell to ~$77K (-4.9%) with BNB -8% and ETH -5.7% on the news. The event tests whether SAFU-plus-treasury can absorb a nine-figure-plus loss without socializing it to users, and reopens the exchange-vs-cold-wallet debate after the Bybit and KelpDAO DPRK hacks.
