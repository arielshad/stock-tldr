<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Huang built Nvidia from a graphics startup into the world's largest public company. The exit follows a week of disclosures including an admitted affair and an intelligence probe; NVDA traded as low as -14% intraday before closing -4.34% at just above $4T market cap, and is down nearly 17% year-to-date.

<strong style="color: #f7ff00;">Who is it for?</strong><br>
Every equity investor, AI-infrastructure allocators, and risk desks watching tonight's Q3 FY27 print.

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Japan's economy contracted for the first time in four quarters in Q3, missing expectations as consumers pulled back and imports surged.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Private consumption fell −0.3% Q/Q for the second straight drop; imports jumped +2.5% on energy, dragging net exports −0.6 pts. Business capex was the sole bright spot at +1.6% Q/Q, led by AI data-center and semiconductor equipment.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US October PPI +6.5% Y/Y — Highest Since Nov 2022; December Fed Hike at ~89% Odds</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">October producer prices cool month-over-month but the 12-month rate climbs to 6.5% — highest since Nov 2022 — hardening the Fed's case for a December rate hike.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BLS October 2026 PPI for final demand rose +0.3% M/M (vs +0.4% est), slowing from September's upwardly-revised +1.4%. The 12-month rate climbed to +6.5%, the highest since November 2022, while core PPI (ex food, energy, trade services) rose +0.5% M/M for a second straight month (+4.9% Y/Y).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Goods prices surged +10.2% Y/Y — the largest since October 2022 — driven by food +1.3% M/M. Services rose +0.2% M/M for a fifth straight gain, led by transportation and warehousing +2.0%. Energy eased −0.1% on crude petroleum −10.3%.
</p>
