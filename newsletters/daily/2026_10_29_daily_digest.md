<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">FOMC Holds at 3.75–4.00% — 10–2 Split as Cook and Hammack Dissent for a Hike</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Fed holds at 3.75–4.00% in a 10–2 split as Cook and Hammack dissent for a quarter-point hike.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Federal Open Market Committee voted October 28 to leave the federal funds target range unchanged at 3.75–4.00%. The vote was 10–2 — Governor Lisa D. Cook and Cleveland Fed President Beth M. Hammack both dissented in favor of a quarter-point rate hike.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Chair Warsh's statement calls activity "expanding at a strong pace" with "strong" productivity growth and "solid" business investment. Unemployment has "barely moved" and "inflation remains high"; the Committee gave no explicit rate path and said it will gather more data to set policy.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The 10–2 split is the first multi-member hawkish dissent of the Warsh chairmanship, signaling part of the Committee sees September's 25bp hike as insufficient against sticky inflation. With no forward guidance, the December meeting remains live for either another hike or an extended hold.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Rates traders, macro desks, and bank-funding analysts.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
