<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Broadcom's AI-semi engine tripled to $16.7B in Q3, but Q4 guide of $34.8B undershot the buyside — stock -5% AH.</p>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The Q4 headline miss vs $35.03B LSEG consensus is what moved the tape — AVGO fell ~5% after hours as buyside models had penciled higher. The guide reset the ceiling on the AI-capex trade heading into Q4.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Japan 10Y JGB tops 3% — first since 1996 — as global bond rout sends US 10Y to 4.81%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">The global bond rout hit a milestone Tuesday when the Japan 10Y broke 3% for the first time since 1996; US 10Y at 4.81% Wednesday, highest since Nov 2023.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Japan's 10-year JGB yield briefly reached 3.005% during Tokyo trading Tuesday Sept 1 — a level unseen since September 1996. The 20Y hit 3.885% and the 30Y climbed to a record ~4.18%. The move rippled to the US, with the 10Y touching 4.814% Wednesday morning, the highest since November 2023.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Two forces are compounding: oil-driven inflation from US–Iran Strait of Hormuz tensions (Brent ~$95, WTI ~$91) pushing breakevens up, and term-premium rebuilding on worsening fiscal outlooks in Japan, the UK and the US. Markets are pricing further BOJ hikes and ~60% odds of a September Fed hike.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
A 3% JGB is the historic level at which Japanese life insurers and pension funds pull capital home rather than buying foreign bonds — that repatriation flow has historically pressed US and European long-end yields higher, and utility, homebuilder and REIT indices are the visible sinks this cycle.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Rates traders, cross-asset macro desks.
</p>

<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
