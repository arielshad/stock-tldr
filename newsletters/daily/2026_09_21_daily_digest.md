<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">BOJ lifts policy rate +25bp to 1.25%, highest since 1995 — but split 7-2 vote and dovish dissent send yen lower and Nikkei to a +1.4% rally.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Bank of Japan raised its overnight call rate target +25bp to 1.25%, effective Sept 24, in a 7-2 split vote. Board members Asada and Sato dissented in favor of holding, arguing core CPI at 1.7% has not yet cleared the 2% threshold.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The BOJ set the complementary deposit rate at 1.25% and basic loan rate at 1.50%. Governor Ueda framed the move as normalization with no preset future pace. Markets read the two dissents as capping the near-term hawkish trajectory.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Japan's second hike in three months confirms a quickening exit from ultra-low rates. Counter-intuitively, USD/JPY rose above 157 and the Nikkei rallied +1.38% to 65,018.95 on the weaker-yen exporter tailwind — the split vote softened pace expectations.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
FX traders, Japan/EM macro desks, JGB watchers, US multinationals with yen exposure.

<strong style="color: #f7ff00;">Why does it matter?</strong><br>
BRK.B closed +0.11% at $509.77, a muted reaction signaling the market had priced in this transition since Abel took the CEO role. The formal handoff removes the last operational role of the most influential US investor of the past half-century.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">FedEx-Advent Consortium Clears 89.8% Tender for €7.8B ($8.9B) InPost Buyout — Amsterdam Delisting Planned</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">FedEx-Advent group clinches €7.8B InPost buyout after 89.8% acceptance on Friday deadline; founder Brzoska keeps CEO seat.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The FedEx and Advent International-led consortium's all-cash offer for Polish parcel-locker giant InPost cleared the required 80% acceptance threshold, with 89.81% of shares tendered at €15.60 per share (deal value: €7.8B / ~$8.9B).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Post-settlement, FedEx and Advent will each hold 37%, founder Brzoska's A&R 16%, PPF 10%. The consortium plans to delist InPost from Euronext Amsterdam and will decide by Sept 23 whether to declare the offer unconditional. Brzoska stays CEO.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
