<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">G7 taps 100M barrels of emergency oil + diesel — Brent -1.5%, WTI -2.7%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">G7 taps 100M barrels of emergency oil + diesel to blunt the Hormuz-war fuel shock.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
G7 members and partners agreed Friday Oct 2 to release up to 100M barrels of oil and diesel from strategic stocks over four months, coordinated through the IEA, with a frontloaded diesel component in the first 20 days.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The decision followed a virtual G7 meeting chaired by Macron; Trump threatened a US diesel export ban if Europe did not tap its stockpiles. IEA's Birol described it as a continuation of the 400M-barrel March 2026 commitment, two-thirds of which had already been released.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Brent fell 1.48% to $100.80 and WTI dropped 2.66% to $90.40 on the news. Goldman Sachs estimates the release offsets only about half of the diesel surge driven by Hormuz disruption — a signal, not a fix.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy desks, macro traders, airline and trucking analysts tracking diesel crack spreads and SPR draw-down pace.
</p>

<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Real Gulf OPEC+ exports remain 60–80% of normal since the US-Israel-Iran war effectively closed Hormuz on Feb 28. Saudi August output was the lowest since 1990. A rollover confirms there is no OPEC+ cushion coming for refined-product markets, keeping the oil complex directly tied to Hormuz newsflow.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Eurozone September HICP +3.8% Y/Y — 3-year high, above +3.6% estimate, energy +18.8%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Euro-area headline inflation jumps back to 3.8% in September — the hottest print since September 2023 — driven almost entirely by a +18.8% Y/Y energy surge.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Eurostat's flash estimate for September 2026 puts euro-area HICP at +3.8% Y/Y — up from 3.2% in August and above the 3.6% Reuters consensus — the hottest read since September 2023. Core inflation (ex energy, food, alcohol, tobacco) edged up to 2.5% from 2.4%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Energy prices jumped 18.8% Y/Y vs 14.3% in August — the single biggest contributor — reflecting base effects and recent crude strength. Services inflation ticked up to 3.2% from 3.0% (sticky wage-driven). Final data lands Oct 16.
</p>
