<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">U.S. July 2026 Jobs Report — NFP -23K, First Monthly Loss Since 2020; S&amp;P Hits Record 7,757 as Fed Hike Odds Crater</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">BLS July NFP prints the first negative payrolls month since 2020, with combined May+June revisions of -103K — S&amp;P sets a fresh record and the market yanks September Fed-hike odds sharply lower.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BLS July 2026 Employment Situation showed nonfarm payrolls declined by 23,000 versus the +80K consensus — the first monthly loss since December 2020. The unemployment rate ticked down to 4.1% from 4.2%, but for the wrong reason: labor force participation slipped as workers left the job market.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
May was revised to +63K (from +129K) and June to +20K (from +57K), a combined -103K. Losses were led by local government education (-50K) and leisure &amp; hospitality (-40K); average hourly earnings rose just 3.2% Y/Y — softest since May 2021. The 10-year Treasury fell ~6bp to ~4.62% and the S&amp;P 500 closed at a record 7,757.64 (+0.62%).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the cleanest labor-side data point yet against Chair Warsh's hawkish tilt — September Fed hike odds collapsed from 57% to 43.9%. Next week's CPI (August 13) is now the swing variable; a cool print flips the base case toward cuts, which Citi already forecasts for October.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, front-end rates desks, and Fed-watchers tracking the September FOMC path.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Berkshire Hathaway (BRK.B) Q2 2026 — Greg Abel Ends 14-Quarter Selling Streak With ~$20B Net Stock Purchases; Cash Falls $32B to $365.5B</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">In his second quarter as CEO, Greg Abel ended Berkshire's 14-quarter selling streak, deploying ~$32B of cash into stock and buybacks.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Berkshire Hathaway published Q2 2026 results on Saturday Aug 8 alongside its 10-Q. Operating earnings rose to $12.98B from $11.16B a year earlier (+16.3% Y/Y). Per the 10-Q, Berkshire was a net buyer of equities for the first time in 14 quarters, purchasing roughly $20B more in stock than it sold.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The combined outflow drew the cash-and-Treasuries pile from a record $397.4B at Q1 down to $365.5B at June 30 — a $31.9B decline. Berkshire also repurchased ~$4.5B of its own shares in Q2 (the largest quarterly buyback since Q1 2021), compared to just $235M in Q1.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is what Berkshire watchers have been waiting for since Buffett handed over on Jan 1 — Berkshire had been a net seller for 14 straight quarters while cash grew. Ending both streaks simultaneously is the clearest signal yet that Abel views current prices as attractive. The Aug 14 13F will reveal which stocks beyond the already-disclosed $10B Alphabet placement Berkshire bought.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Large-cap value investors and Berkshire watchers tracking Abel's capital-allocation signals.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Cloudflare tops Q2 estimates, lifts full-year outlook, and says AI-agent traffic has crossed half the network for the first time.</p>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
