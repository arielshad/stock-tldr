<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">10Y Treasury tops 5.22% — highest since 2007 — as NY Fed's Williams calls a 2026 hike 'reasonable'</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Williams pivots from 'wait and see' to 'reasonable to hike again this year' — 10Y yield spikes to a 19-year high and rate-hike bets surge.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
NY Fed President John Williams told the London Macro Policy Forum that investor pricing implying another rate hike this year "seems to me a reasonable way of thinking about it," citing above-target inflation, high energy prices, and AI-capex-driven demand. It marks a hawkish pivot from his Sept 2 "wait and see" framing.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The 10Y Treasury yield spiked to 5.225% intraday — the highest since July 2007 — before settling near 5.15%. The 30Y hit its highest since 2004 and the MOVE index jumped to 104. Fed-funds-futures-implied odds of an October 28 hike surged to 77.5% from 53% the day before Williams spoke.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Williams is a permanent FOMC voter and the traditional number-two voice at the Fed. His pivot removes the last dovish anchor from the committee and pins the front end of the curve to another hike this year. The 5.22% level is territory the S&P 500 has not had to digest since before the GFC.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Rates traders, macro desks, anyone with duration exposure — mortgage rates track the 10Y; equity valuations compress at higher discount rates.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">U.S. September UMich final sentiment 48.1 — 4-month low; year-ahead inflation expectations jump to 4.6%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">UMich September final: sentiment slides to a 4-month low as year-ahead inflation expectations jump to 4.6%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The University of Michigan's final September 2026 consumer sentiment reading came in at 48.1, down from 51.7 in August — a 7.0% monthly decline and the weakest print in four months.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The forward-looking Expectations Index dropped 10.1% to 46.3 as households turned sharply more downbeat on personal finances. Year-ahead inflation expectations climbed to 4.6% from 4.0% in August — the highest since June — and long-run 5–10Y expectations ticked to 3.4% from 3.3%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the second consecutive print showing inflation re-anchoring higher, reinforcing NY Fed's Williams' call that another 2026 hike is "reasonable" and keeping October-hike odds firmly bid. For rates traders it supports the 10Y's move above 5.10%.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks — next catalyst is September PCE on October 2.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Akamai lands its largest-ever customer deal — a $11.6B/7yr Anthropic cloud commitment plus a warrant for up to 5% of the company.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Akamai Technologies (AKAM) announced a seven-year, $11.6 billion contractual commitment with Anthropic to support the AI lab's CPU workload demands on Akamai Cloud. An option to expand by up to $9B brings the total potential value to ~$20.6B, plus Anthropic receives a warrant for up to ~5% of Akamai common stock.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The $11.6B commitment requires ~$5.5B of associated capex; Akamai raised its 2026 capex outlook by ~$1.7B. The warrant covers 7.7M as-converted shares at a $111.33 strike, with ~2% vesting on the initial commitment. Company forecasts $150–300M of Anthropic revenue in 2027 and a ~$1.7B annual run-rate by 2028.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is by far the largest customer deal in Akamai's history and validates its multi-year pivot from CDN to AI cloud. It also expands Anthropic's compute footprint beyond AWS and Google — mirroring how OpenAI has spread infrastructure deals across Oracle, Microsoft, and CoreWeave.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-capex traders, cloud infrastructure desks, anyone tracking hyperscaler compute diversification — AKAM ran to $130.66 AH, well above the $111.33 warrant strike.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Oracle (ORCL) -~6% — invokes force majeure on $165B Project Jupiter after NM pipeline denied twice</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Oracle sends a force majeure notice to Blue Owl's Stack Infrastructure over Project Jupiter after NM regulators twice deny the pipeline that feeds the campus.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Oracle told Blue Owl-controlled developer Stack Infrastructure that circumstances beyond its control may prevent Project Jupiter — the 2.45-gigawatt, $165B New Mexico data center campus anchoring the Stargate AI buildout with OpenAI and SoftBank — from coming online by its 2028 deadline.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The core problem: New Mexico's State Land Office denied Energy Transfer's 17-mile gas pipeline twice (March and July), pushing the in-service date to Feb 1, 2027. Bloom Energy's solid-oxide fuel cells — the campus's power spine — cannot run without that gas. About 20 banks lent ~$18B to build the campus; that debt is now quoted below 90 cents on the dollar.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the first crack in the Stargate story — a top-3 hyperscaler is publicly hedging its exposure to an AI-datacenter mega-project. Blue Owl (OWL) fell as the debt gapped down; Bloom Energy (BE) traded off with the campus's fuel-cell demand in doubt.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-capex traders, private-credit and BDC desks, power-and-infra analysts — watch the Energy Transfer permit and the Blue Owl 8-K response.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">GRAIL (GRAL) — FDA panel votes 7-2 that Galleri multi-cancer blood test's benefits outweigh risks</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">FDA advisory panel backs Grail's Galleri 7-2 on benefit-risk — the first federal endorsement of any multi-cancer early-detection screen — as the final FDA decision looms.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The FDA's Molecular and Clinical Genetics Devices Panel voted on GRAIL's premarket approval (PMA) application for Galleri, a blood test that scans a single draw for DNA fragments shed by ~50 cancer types. The panel voted 7-2 (1 abstain) that benefits outweigh risks, 10-0 on safety, and 6-4 on effectiveness.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
GRAIL submitted the PMA on January 29, 2026; Galleri holds FDA Breakthrough Device designation. About 117,000 people paid out-of-pocket for Galleri in H1 2026 (cash-pay only, ~$949/test). Advisory committee recommendations are non-binding, but the FDA typically follows panels.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the first-ever federal endorsement of any multi-cancer early-detection (MCED) test, setting a regulatory template the entire category (EXAS, NVTA, ILMN-adjacent) has been waiting for. A PMA grant opens the door to CMS reimbursement conversations — the prize that would dramatically expand addressable market.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Diagnostics analysts, biotech long/short, healthcare policy desks — watch the 6-4 effectiveness split for tight labeling conditions in the final PMA decision.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">BofA rips Nike PT to $30, tags it Underperform ahead of Oct 1 earnings — dividend flagged as at-risk on cut EPS.</p>
