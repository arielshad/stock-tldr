<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Binance $6.3B Hack — Largest Crypto Theft Ever</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Binance says a $6.3B hot-wallet exploit — the largest crypto theft ever — is 90% backed from company funds, with the FBI pointing to North Korea.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
On Thursday Oct 29 Binance disclosed a security incident that drained ~$6.3B of client token assets from its hot wallets, suspending withdrawals while the breach was triaged. By Saturday the FBI publicly named TraderTraitor — North Korea's state-sponsored unit — as the attacker.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
A compromised DevOps engineer's laptop gave attackers access to withdrawal-signing infrastructure; Binance earmarked ~$6.34B from SAFU, Futures Insurance Fund, and treasury to make users whole. ~$3B in affected addresses were frozen on-chain — Tether froze $1.567B USDT, Circle $800M+ USDC — with withdrawals targeted to resume Sunday Nov 1.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Bitcoin fell ~5% to ~$77K and BNB -8%, with the Fear &amp; Greed Index flipping to 'fear'; the event tests whether exchange-held reserves can actually absorb a nine-figure-plus loss without socializing it to users. Stablecoin issuers' rapid freeze response — $1.5B of USDT and $800M+ USDC blocked in hours — becomes the new benchmark for post-hack asset containment.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Crypto desks, exchange risk managers, and stablecoin issuers tracking on-chain freeze mechanics.
</p>

</p>

FX desks, JGB rates traders, and Japan equities investors watching the December 17-18 BOJ meeting.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US Q3 2026 GDP Advance +3.4% — Above Estimate, Nearly Double Q2's Pace</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">US Q3 GDP advance prints +3.4% — above estimate and almost double Q2's pace — with price indexes sharply cooler.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BEA's Q3 2026 advance GDP estimate came in at +3.4% annualized on Thursday October 29, beating ~3.2% consensus and up sharply from Q2's final +2.2%. Real final sales to private domestic purchasers — the cleanest demand signal — accelerated to +4.9%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Growth was broad — consumer spending (healthcare, food services), business investment (information-processing equipment), and government outlays all contributed. The quarterly PCE price index decelerated sharply to +2.1% (from Q2's +5.0%) and core PCE to +2.5% (from +3.3%).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
A hotter-than-expected growth print combined with cooler Q3 price indexes gives the Fed a mixed signal — strong growth argues against easing, but the price deceleration supports it. The 10-year yield slipped to ~4.99% late Thursday as the GDP beat combined with single-stock risk-off drove some flows into bonds.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Series I Bond Rate Set at 5.51% — Fixed Rate Hits 20-Year High of 1.40%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Treasury's new Series I bond composite rate jumps to 5.51% for the Nov 2026 – Apr 2027 issue window as the fixed component rises to a 20-year high of 1.40%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The U.S. Treasury set the Series I savings bond composite rate at 5.51% on Friday October 30 for bonds purchased November 1, 2026 through April 30, 2027 — up from 4.26% in the prior window. The fixed component rose to 1.40%, the highest since November 2006.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The composite combines the 1.40% fixed rate (locked for the bond's lifetime at purchase) and a 2.04% semi-annual inflation component derived from CPI-U, annualizing to ~4.08%. Minimum hold is 1 year; redemption within 5 years forfeits the last 3 months of interest; bonds accrue up to 30 years.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The 1.40% fixed rate — the highest since 2006 — locks in a real yield competitive with 5-year TIPS for the bond's full lifetime, even if CPI moderates. September CPI at +3.7% Y/Y and the NY Fed's one-year inflation outlook jumping to 3.9% (a three-year high) keep the inflation leg elevated.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Retail savers and fixed-income desks tracking real yields in a sticky-inflation environment.
</p>
