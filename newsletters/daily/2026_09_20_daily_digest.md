<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Bank of Japan hikes to 1.25% — highest since 1995 — but split 7-2 vote sends yen lower, Nikkei +1.4%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">BOJ lifts policy rate +25bp to 1.25%, highest since 1995 — but split 7-2 vote and dovish dissent send yen lower and Nikkei to a +1.4% rally.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Bank of Japan raised its unsecured overnight call rate target by 25 basis points to 1.25% from 1.00% at Friday's Sept 18 policy meeting — the second hike in three months and the highest policy rate since 1995. The board split 7-2, with Toichiro Asada and Ayano Sato dissenting for hold.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The complementary deposit facility rate was set at 1.25% and the basic loan rate at 1.50%, effective Sept 24. Ueda framed the move as normalization with no preset pace for further increases; markets read the two dissents as capping near-term hawkish trajectory.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The reaction was counter-intuitive: USD/JPY climbed above 157 and the 2Y JGB yield fell 2.5bp as the split vote softened pace expectations. Nikkei rallied to 65,018.95 (+1.38%) on the weaker-yen exporter tailwind. This quickens the hike cadence to 3 months vs. the prior 6-month gap.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, FX desks, JGB watchers, and Japan equities investors tracking Japan's exit from ultra-low rates.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Warren Buffett ends a 61-year run as Berkshire chairman; his son Howard takes the chair, Greg Abel keeps the CEO seat.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
BRK.B closed +0.11% at $509.77 — a muted reaction signaling the market had priced in the transition since Abel took CEO in January. The formal end of Buffett's chairmanship removes the last operational role of the most influential U.S. investor of the last half-century.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Long-only equity allocators, Berkshire watchers, and corporate-governance analysts tracking succession at one of the world's largest companies.
