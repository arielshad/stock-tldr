<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US 10-Year Treasury Yield Tops 5% for First Time Since Oct 2023</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">US 10-year yield printed 5.014% intraday — first 5-handle since 2023 — as oil, hot CPI and Fed-hike odds converged ahead of today's FOMC.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The benchmark 10-year US Treasury yield rose above 5% for the first time since October 2023 on Mon Sept 14, peaking at 5.014% before easing to ~4.95%. The move came alongside Brent crude above $108 on the Saudi East-West pipeline shutdown and a hot August CPI print showing core services still sticky.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
<a href="https://www.cmegroup.com/markets/interest-rates/cme-fedwatch-tool.html" style="color: #f7ff00;">CME FedWatch</a> priced ~88% odds of a 25bp hike at Wednesday's FOMC — up from ~70% before Friday's CPI. Weak dealer take-up at recent Treasury buybacks and continued net issuance to fund the 2026 budget gap amplified the yield move.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
5% is the psychological line that broke bond funds in Oct 2023 and put duration pain back on the table. Long-duration equities took the hit — Nasdaq 100 -1.7%, SOX -5.7%. If today's FOMC delivers a hike with a hawkish dot plot, the 10Y could push toward 5.10–5.20%.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Rates traders, long-duration equity holders, and mortgage desks — with the FOMC decision landing today, this is the single most important macro backdrop to monitor.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Amodei's "We Must Pace the Frontier" Essay — Altman and Musk Endorse; Futures Drop</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Three top frontier-AI CEOs converge on a rare public consensus that the pace of AI capability gains must slow — first cross-industry safety alignment.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Anthropic CEO Dario Amodei published <a href="https://darioamodei.com/post/we-must-pace-the-frontier" style="color: #f7ff00;">a ~3,800-word essay</a> on Fri Sept 12 calling for the AI industry to deliberately slow model capability gains. Within hours, OpenAI's Sam Altman and xAI's Elon Musk publicly endorsed the call.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Amodei proposes embedded third-party evaluators (naming <a href="https://metr.org" style="color: #f7ff00;">METR</a>), safety-standard coordination among democratic-country AI labs, and eventual global coordination. Altman committed OpenAI to independent evaluators with employee-level access; Musk replied on X: "Dario is right."
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The pacing consensus lands directly on the AI-capex trade that has led equity markets this year. Nasdaq 100 futures fell 1.2% at Sunday's open, twice the S&P 500's drop, with chips and hyperscalers most exposed.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-capex traders and chip/hyperscaler positioning desks — the essay is the macro backdrop to every AI-related move this week.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Wall Street splits the "AI trade" in two: chips get sold, cyber-defense gets bought as Amodei's slowdown essay reframes AI as a threat surface.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
<a href="https://finance.yahoo.com/quote/CIBR/" style="color: #f7ff00;">First Trust NASDAQ Cybersecurity ETF (CIBR)</a> closed Mon Sept 14 at $100.05, up 5.99% — one of its largest single-day gains on record — while the Philadelphia Semiconductor Index fell 5.9% in the same session.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
CIBR's top holdings all surged: <a href="https://finance.yahoo.com/quote/CRWD/" style="color: #f7ff00;">CrowdStrike (CRWD)</a> +13.85% to $235.38, <a href="https://finance.yahoo.com/quote/PANW/" style="color: #f7ff00;">Palo Alto (PANW)</a> +13.09% to $373.94, <a href="https://finance.yahoo.com/quote/ZS/" style="color: #f7ff00;">Zscaler (ZS)</a> +16.52% to $191.73 — with no company-specific catalyst, only the Amodei essay and CrowdStrike CEO Kurtz's "securing AI's progress is cyber's job" counter-narrative.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Corning (GLW) -13.7% — Biggest Drop Since July After Quiet $2B Goldman ATM Filing</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Corning drops 13.7% — biggest single-day since July 28 — after quietly filing to sell up to $2B of stock via Goldman.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
<a href="https://finance.yahoo.com/quote/GLW/" style="color: #f7ff00;">Corning (GLW)</a> filed an 8-K after Fri Sept 11 close disclosing an Equity Distribution Agreement with Goldman Sachs to sell up to $2B of common stock via at-the-market. Shares closed -13.7% to $143.60 — the biggest one-day drop since the -18% Q2 guide crash on July 28.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Unlike a conventional secondary, an ATM sets no fixed price or share count — Goldman drips shares into the open market at a 1.0% commission. Net proceeds are earmarked for "general corporate purposes," no disclosed spending target. Optics peers fell in sympathy: <a href="https://finance.yahoo.com/quote/COHR/" style="color: #f7ff00;">Coherent (COHR)</a> -11%, <a href="https://finance.yahoo.com/quote/LITE/" style="color: #f7ff00;">Lumentum (LITE)</a> -9%, <a href="https://finance.yahoo.com/quote/FN/" style="color: #f7ff00;">Fabrinet (FN)</a> -6%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The market read this as unplanned dilution to finance AI-optics buildout after multi-year fiber deals with Nvidia and Amazon. The "if they had a great quarter coming, why raise now?" signal amplified the move beyond the ~1.6% dilution math.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-optics and semi-cap-equipment desks, GLW long-onlies, and event-driven traders on ATM programs.
</p>
