<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Salesforce prints a record quarter, raises FY27 guide $300M, and pairs it with a Claude-powered Agentforce co-launch.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Salesforce reported Q2 fiscal 2027 results after Wednesday's close. Revenue reached a record $11.35B (+11% Y/Y), non-GAAP EPS $5.90 (+103% Y/Y), and free cash flow $1.1B (+81% Y/Y). Alongside the print, Salesforce and Anthropic unveiled Claudeforce, a joint interface that layers Claude on top of Salesforce data and workflows.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Agentforce annualized recurring revenue passed $1.5B (+240% Y/Y); combined Agentforce + Data 360 ARR is nearly $3.9B (+210%). Management raised the FY27 revenue outlook to $46.1–$46.4B with a 34.3% non-GAAP op margin target.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The print snaps a run of tepid growth quarters and gives Salesforce a credible AI-monetization story. Claudeforce reaches general availability in September and is due in every seller's demo by Dreamforce. CRM closed +11.9% to $252.23, dragging ServiceNow and Adobe higher across the enterprise-SaaS complex.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Enterprise-software, AI-agent, and SaaS-multiple watchers.
</p>

Net sales fell 2% Y/Y to $3.7B with total comparable sales down 1%, but adjusted diluted EPS of $0.52 topped the ~$0.42 Street estimate. <p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Workday beats and raises FY27, but Q3 subscription guide of $2.515B (12%) disappoints — shares -7% AH.</p>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US July 2026 PCE — headline +3.7% Y/Y (0.1pt above est), core PCE +3.3% Y/Y in line; Fed's preferred inflation gauge stays sticky above target</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">July PCE hotter on the headline (3.7% Y/Y), core in line (3.3%) — inflation grinding sideways above the Fed's 2% target.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Personal income rose 0.4% M/M and personal spending rose 0.2% M/M. Core PCE held at 3.3% Y/Y for a third consecutive month. The release landed alongside the unrevised Q2 GDP second estimate of +1.5% annualized, with corporate profits jumping $400.9B in Q2 vs $74.4B in Q1.
