<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Investors read Friday's founder-selling disclosure as an offset to Oracle's blowout Q1 FY2027 print (cloud infra +121% Y/Y, RPO $664B). The Saturday cancellation reverses the negative signal ahead of Monday's open — "no other plans to sell" is unusually absolute language.

ORCL holders and insider-signal watchers monitoring whether the cancellation holds into Monday's open.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Nasdaq commits $100M to Kraken parent Payward at $21B — Nasdaq Equity Tokens (NETs) target Q2 2027 with full voting rights</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Nasdaq puts $100M into Kraken parent to push equities onchain — NETs launch penciled Q2 2027 with full voting rights.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Nasdaq Ventures announced a $100M investment into Payward (parent of Kraken) at a $21B valuation on Thu Sept 10. The deal expands the March 2026 "equities transformation gateway" partnership and puts Nasdaq's market surveillance tech across every Payward trading venue.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Payward adopts Nasdaq's real-time surveillance across crypto, equities, tokenized equities, futures, and options. The two firms are building Nasdaq Equity Tokens (NETs) — onchain shares carrying the same voting rights as ordinary equity — with launch targeted for Q2 2027.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
First major traditional exchange to commit real capital plus surveillance rails to a tokenized-equity crypto exchange. "Same voting rights as ordinary shares" will force the SEC to decide whether onchain equities fit existing frameworks.
