<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US September 2026 Jobs Report — NFP +29K vs +84K est</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">September payrolls crater to +29K vs +84K est, July revised to -10K — Fed October hike bets collapse.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
BLS released the September 2026 Employment Situation on Fri Oct 2. Nonfarm payrolls rose just 29K vs the 84K Dow Jones consensus. Unemployment ticked up to 4.2% and average hourly earnings growth slowed to +3.0% Y/Y — the softest annual pace since May 2021.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
July was revised from +21K to -10K (now negative) and August from +162K to +133K, cutting a combined 60K from prior prints. Health care led with +17K; construction added +11K; professional/business services shed 9K and financial activities -7K.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
October Fed hike odds collapsed to ~20% from ~64% a week ago. Equities rallied — Nasdaq +1.23% to a record close at 27,201 and S&P 500 +0.75% to 7,723. The report puts the hawkish FOMC path squarely in doubt heading into Oct 28–29.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, and Fed watchers recalibrating the October hike probability. Next catalysts: October CPI/PPI, then the Oct 28–29 FOMC.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Nikkei's Toshiba HDD-capacity-doubling scoop sends STX and WDC both down ~10% on fears the AI storage supply squeeze eases.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Seagate and Western Digital each closed down ~10% on Friday after Nikkei reported Toshiba plans to spend ~¥60B (~$400M) to double its HDD output at its Philippines plant by fiscal 2027. STX fell to $848.99, WDC to $415.29.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Toshiba, currently the smallest of three HDD makers at ~10% capacity share, targets 30% with new lines supporting drives with up to 40% higher per-unit capacity — consistent with its plan to mass-produce 65-TB-class HDDs by 2030.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
STX was up ~210% YTD and WDC ~150% YTD on the "AI data centers run out of storage" thesis. A credible third-player capacity expansion directly challenges the supply-tightness narrative that drove both stocks' 2026 re-rating.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Semis/storage traders and AI-infra desks reassessing the HDD supply story. Next catalysts: WDC and STX fiscal Q1 earnings prints later this month.
</p>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">onsemi (ON) Amends Synaptics (SYNA) Merger to $5.7B All-Cash at $123/Share</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">onsemi flips the Synaptics deal to all-cash at $123/share, $5.7B — SYNA jumps ~14%, ON jumps ~5%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
onsemi and Synaptics filed an Amended and Restated Merger Agreement via 8-K on Thu Oct 1. Under the new terms, ON will acquire SYNA for $123 per share in cash (~$5.7B), replacing the June 25 all-stock structure (1.350 ON shares per SYNA, ~$7B at signing).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The amendment follows an unsolicited proposal Synaptics received Sept 2 from a strategic party. Financing is ON cash on hand plus a $2.45B committed term loan from Morgan Stanley. U.S. antitrust clearance is already obtained; closing targets mid-2027 subject to SYNA shareholder approval.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The original stock structure cratered ON -23.66% on June 26 on dilution fears; the cash restructuring removes that overhang and shifts risk to ON's balance sheet. SYNA holders get a fixed $123 at close — removing the ON-share re-rating risk that had kept SYNA trading well below implied value for months.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Semis M&amp;A desks and SYNA/ON holders tracking the proxy filing and mid-2027 close timeline.
