<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Nvidia Q3 FY27: Revenue $115.8B (+103% Y/Y), Q4 Guide $130B — First Print Under Interim CEO Kress</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Nvidia Q3 FY27 revenue doubles to $115.8B, guides Q4 to $130B — first print under interim CEO Kress after Huang resignation.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Nvidia reported fiscal Q3 FY2027 results on Nov 17 — the first print since founder Jensen Huang resigned as CEO on Nov 12. Revenue hit $115.8B, up 103% Y/Y, beating LSEG consensus of ~$109.1B; non-GAAP EPS was $2.68 vs ~$2.48 expected.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Data Center revenue was $107.6B (+110% Y/Y), ~93% of the total. The Q4 outlook of $130B ± 3% excludes China DC compute; Nvidia returned $28.1B to shareholders in Q3 with ~$227.3B remaining on the buyback authorization.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The world's largest public company beat its Q3 guide by ~$7.8B and set Q4 above consensus by ~$4.9B — a direct answer to the AI-capex demand debate that drove the Nov 5 Nasdaq correction. Board chairman Harvey Jones confirmed the board will not reinstate Jensen Huang.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Mega-cap AI traders, risk/vol desks, and semiconductor specialists tracking AMD, Broadcom, and hyperscaler capex read-throughs.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Wall Street Journal reported Nov 17 that the SEC opened a civil investigation into whether Nvidia's disclosures misled investors following Huang's Nov 12 resignation. Both the SEC and Nvidia declined to comment.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
WSJ calls it a civil probe — fact-finding, not enforcement — examining Nvidia's disclosures around Huang's conduct and his relationship with an executive at Nvidia customer Megaspeed. The report landed hours before Nvidia's Q3 FY27 earnings call.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
An SEC civil probe of the world's largest public company adds a governance overlay on top of the Huang resignation, DOJ inquiries, and a House GOP briefing request. NVDA has fallen more than 10% since Nov 12; probes of this scope typically take 12–18 months.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Mega-cap tech traders, governance/risk desks, and event-driven funds watching the NVDA governance overhang.

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
