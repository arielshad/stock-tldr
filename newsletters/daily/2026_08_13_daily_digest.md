<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Cisco (CSCO) Q4 FY26 — $17.3B revenue, $9.3B AI orders, FY27 guide crushes consensus</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Beat-and-raise with a $9.3B AI order tally — but a 60% YTD rally set the bar high, so shares faded after popping.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Cisco reported fiscal Q4 and full FY26 results on Aug 12 — revenue, EPS, Q1 guide, and FY27 guide all topped Wall Street. The headline story was AI networking: $4B of hyperscaler orders in Q4 alone brought FY26 total AI orders to $9.3B, roughly 4.5× fiscal 2025.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Q4 revenue $17.3B (+18% Y/Y) vs $16.82B est; non-GAAP EPS $1.22 (+23%) vs $1.17 est. FY27 revenue guide $72.2–$73.4B obliterates the $68.69B consensus, with $7.5B of AI infrastructure revenue targeted in FY27 (up from ~$4B in FY26).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Cisco is the primary read on U.S. hyperscaler networking capex — a $4B revenue beat over consensus implies AI-driven demand is still accelerating. But CSCO entered the print up ~60% YTD and faded 4% AH on sell-the-news mechanics; strong read-through for ANET, AVGO, MRVL, and CIEN.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-networking longs and mega-cap earnings watchers tracking hyperscaler capex trajectories.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">U.S. July 2026 CPI — headline +3.4% Y/Y, core +2.5%, second straight month of deceleration</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">In-line July CPI: headline 3.4% Y/Y, core down to 2.5% — cools the September-hike case a notch after last week's -23K payrolls.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BLS released July 2026 CPI at 8:30 a.m. ET on Aug 12. Headline CPI rose 0.1% M/M and 3.4% Y/Y; core (ex food &amp; energy) rose 0.2% M/M and 2.5% Y/Y — both exactly matching LSEG economist consensus.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Shelter (+0.1% M/M) drove roughly two-thirds of the monthly headline gain while energy fell 1.5%. Year-over-year, headline eased from June's 3.5% and core slipped from 2.6% — the second consecutive month of deceleration on both series.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the final CPI print before Kevin Warsh's Sept 16–17 FOMC. After last week's -23K payrolls miss, an in-line CPI takes urgency out of the September hike case — but sticky shelter keeps core above 2% and prevents a dovish read.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Rates desks, macro traders, and Fed watchers tracking the trajectory into the September FOMC decision.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">CoreWeave posts +112% Y/Y revenue with a $104B backlog and $25B of net-new deals already in Q3 — GPU-cloud demand is not slowing.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
CoreWeave, the Nasdaq-listed AI cloud provider, reported Q2 2026 on Tuesday Aug 11. Revenue more than doubled Y/Y, backlog swelled to ~$104B, and management flagged an additional $25B of net-new customer commitments already booked in the first weeks of Q3.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
A $104B backlog plus $25B added in three weeks means CRWV is pre-sold through 2027 — capacity, not chips, is the binding constraint. Comps DLR, IREN, APLD, and NBIS trade in sympathy; debt load and GAAP losses remain the counter-argument.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
