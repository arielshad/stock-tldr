<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">FTC + 22 State AGs Sue Amazon Over $20B+ Ad-Auction Scheme — AMZN -2.7%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">22-state coalition joins FTC to accuse Amazon of running fake second-price sponsored-ad auctions and pocketing $20B+ in secret overcharges over 7 years.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The FTC, joined by 22 state attorneys general (bipartisan — 11 R, 11 D), filed suit against Amazon in the US District Court for the Western District of Washington on Monday Aug 31. The complaint alleges that Amazon's sponsored-products advertising business, one of its highest-margin segments, was rigged.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
In a textbook second-price auction the winner pays one cent above the second-highest bid. The FTC alleges Amazon added an undisclosed "soft reserve price" that quietly raised the floor, so advertisers paid their full winning bid roughly 80% of the time over more than 7 years.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Sponsored ads run at a $65B+ annualized clip and are the highest-margin piece of Amazon's retail P&amp;L — any injunctive redesign of the auction mechanic hits gross-profit dollars directly. AMZN closed -2.7% below $260, its worst day in over a month, and dragged the S&amp;P 500 into the red.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Regulatory / antitrust desks, digital-ad analysts, and mega-cap tech longs.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">PG&amp;E (PCG) -18%, Edison (EIX) -23% — California SB 492 Strips Liability Shield</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">California utilities re-priced overnight after lawmakers strip subrogation shield and $6B per-fire cap from SB 492.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
California's legislative session closed Saturday Aug 29 with passage of Senate Bill 492 — a bill that addresses wildfire claim payment speeds but leaves out the sweeping investor protections utilities had lobbied for all year. Governor Newsom's original proposal ended insurer subrogation lawsuits and capped per-fire liability at $6B; both were dropped after insurance-industry pushback.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The final bill preserves insurer subrogation rights, does not add a Wildfire Fund replenishment mechanism, and does not extend the 2028 fund sunset. Analysts moved fast: Mizuho cut PCG, EIX, and SRE to Neutral; BMO cut PCG to Market Perform; Wells Fargo moved to Equal Weight.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
EIX fell 23.1% to $54.22 — its worst single-day print in more than 25 years — on unresolved Eaton Fire liability exposure. XLU dropped only 1.0%, confirming the market reads this as California-specific statutory risk, not a broader utility repricing.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Utility desks, muni/credit analysts, and California policy watchers.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">NVIDIA Invests $3.5B in MediaTek Convertible Bonds to Anchor NVLink Fusion in Custom AI Chips</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Nvidia writes a $3.5B convertible-bond check to MediaTek to anchor NVLink Fusion inside custom AI accelerators as hyperscalers try to move off Nvidia GPUs.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Nvidia and MediaTek announced Monday Aug 31 that Nvidia will buy $3.5B of MediaTek convertible bonds, deepening a partnership that already spans data-center AI, AI PCs, and automotive. MediaTek is Taiwan's largest fabless chip designer.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
MediaTek will adopt Nvidia's NVLink Fusion — the interconnect Nvidia pitches to hyperscalers building custom XPUs so those chips can still plug into Nvidia rack-scale systems. The deal also extends prior collaborations on RTX Spark and DGX Spark AI PC chips and on Nvidia-based platforms inside MediaTek's Dimensity Auto automotive SoCs.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
AWS, Google, Microsoft, OpenAI, and Anthropic are all building custom accelerators to reduce Nvidia dependency. By anchoring NVLink Fusion inside MediaTek's custom silicon — a direct competitor to Broadcom and Marvell for that XPU-design business — Nvidia keeps its interconnect moat around the very chips designed to compete with it. NVDA closed roughly +1% at ~$220.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-infrastructure investors, semis desks, and hyperscaler capex watchers.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">ONEOK Buys Brazos Midstream Permian Assets for $4.4B — Apollo Injects $9B at Capped 7% IRR</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">ONEOK doubles its Midland Basin footprint with a $4.4B Brazos buy and pulls in $9B of Apollo equity capped at a 7% return.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
ONEOK announced Sunday afternoon Aug 30 that it will acquire Brazos Midstream Holdings' Permian Midland Basin gas gathering and processing assets from Morgan Stanley Infrastructure Partners for $4.425B in cash. To fund the deal and simultaneously delever, Apollo funds are committing $9B for a non-voting minority equity stake capped at 7.0% IRR for the first nine years.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
ONEOK will use ~$5B of the Apollo proceeds to pay down existing debt to ~3.25x debt-to-EBITDA. The Brazos assets more than double OKE's Midland Basin processing capacity to ~2.3 Bcf/d on ~600,000 dedicated acres under long-term contracts. The deal prices at ~7.5x 2027E EBITDA (including ~$80M synergies) and closes Q4 2026 subject to HSR clearance.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is one of the largest midstream deals of 2026, continuing OKE's consolidation run after Magellan (2023) and EnLink (2024). Apollo's capped-return structure behaves like hybrid preferred equity, letting OKE keep upside without adding debt to the balance sheet. OKE +0.53% to $95.55 Monday.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy desks, midstream investors, and PE credit analysts.
