<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US Strikes Larak Island, Iran Retaliates in Jordan — Oil +~2%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">First direct US-Iran military exchange since the early-August Hormuz-reopening framework; WTI +1.8% to $84.94, Brent +1.9% to $89.79 at Asia open.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
CENTCOM struck two IRGC rocket launchers on Larak Island on Sunday Aug 30, ending a month-long lull after crews were seen preparing sea mines for the Strait of Hormuz. Iran's IRGC acknowledged casualties and launched a pre-dawn missile-drone salvo it named "Punishment of the Aggressor" against two US-linked bases in Jordan.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Jordan's armed forces intercepted eight missiles that entered Jordanian airspace at dawn Monday Aug 31; no casualties were reported at King Hussein or Muwaffaq Salti/Al Azraq bases. The exchange followed an unclaimed projectile striking an inbound tanker ~12 nm north of Khasab, Oman on Saturday.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The Strait of Hormuz carries ~25% of seaborne oil trade and is already running at ~24 tanker transits/week vs ~130/day pre-war; a re-mined strait would undo the ~$5/bbl risk-premium unwind since the Aug 2 deal announcement. WTI and Brent both gapped higher at Asia open, retracing part of August's slide.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy desks, macro traders, and geopolitical event traders watching Hormuz shipping and oil risk-premium dynamics.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Warsh's Jackson Hole Debut Leans Hawkish — 2Y Yield +8bp to 4.31%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Fed Chair Kevin Warsh says inflation still "above our 2 percent target," formally distances the Fed from forward guidance; S&P -0.25% to 7,711.76, still +0.5% on the week.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Warsh delivered his first Jackson Hole keynote — titled "In Our Time" — on his 100th day as Fed Chair, three months after replacing Jerome Powell. His central message: inflation is above target and recent summer readings "do not tell me that underlying trends have meaningfully improved."
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Warsh declared forward guidance "has overstayed its welcome" in normal times, signaling a return to a pre-2008-style Fed that relies on real-time data rather than predetermined rate commitments. The Fed funds range remains unchanged at 3.50–3.75% after the 9-3 July hold; three dissenters wanted a hike.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Bond markets read it as a hike signal — the 2Y note jumped ~8bp to 4.31%, its highest since late July, and front-end rates markets priced in a higher probability of a September move. September FOMC (Sep 16–17) is now in play alongside the August jobs report (Sep 5) and CPI (mid-Sep).
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, front-end rates desks, and FX desks repricing the September hike probability and watching for follow-on economic data.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">NVDA -4.57% to $217.55 — Pauses $36B AI Compute Partnership on Antitrust Worries</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Nvidia pulls the plug on new sign-ups for the revenue-sharing GPU financing program just two months after its July launch, erasing roughly a third of the post-earnings rally.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Wall Street Journal reported Friday that Nvidia has paused the AI Compute Partnership — a revenue-sharing financing program launched in July to help smaller cloud providers (neoclouds) buy Nvidia GPUs, with ~$36B in six-year commitments disclosed in a quarterly filing.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Nvidia set a baseline hourly GPU rate covering providers' costs and took 50% of revenue above that threshold, also committing to lease unsold capacity itself. Nvidia insiders flagged antitrust exposure, and cloud providers pushed back on a clause requiring Nvidia's approval of end-customers.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The pause re-opens the "circular financing" debate that rattled chip names in late July and caps a week where NVDA had already rallied 5% on Q2 FY27 earnings — Friday's -4.6% erased roughly a third of that gain. Nvidia left the door open to restructuring the program later.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI-infra investors, chip traders, and neocloud watchers tracking the sustainability of GPU financing structures.
</p>

<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Trump Announces US–Venezuela Oil Deal: 55% US Share of 65B-Barrel JV, 1.5M bpd Target</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Sep '26 wheat closes $7.67 (+3.27%), Dec '26 touches $7.9025 intraday — highest since Feb 2023 — as Russia signals renewed Black Sea strikes and Novorossiysk shipping stalls.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
