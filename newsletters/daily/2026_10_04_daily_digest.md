<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">G7 taps 100M barrels of emergency oil + diesel over four months — Brent -1.5%, WTI -2.7%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">G7 taps 100M barrels of emergency oil + diesel to blunt the Hormuz-war fuel shock.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
G7 members and partners agreed Friday Oct 2 to release up to 100M barrels of oil and diesel from strategic stocks over four months, coordinated through the IEA, with a frontloaded diesel component in the first 20 days.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The decision followed a virtual meeting chaired by Macron, with Treasury Secretary Bessent and President Trump pressing Europe to tap its diesel stockpiles. The IEA describes it as a continuation of the 400M-barrel commitment from March 2026, of which two-thirds had already been released.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Brent fell 1.48% to $100.80 and WTI dropped 2.66% to $90.40 after the news. Goldman Sachs estimates the release can offset only about half of the diesel surge driven by Strait of Hormuz disruption from the US-Israel-Iran war.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy desks, macro traders, and airline + trucking analysts.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Tesla (TSLA) +~5.5% to ~$373 — Q3 2026 deliveries 486,532 beat ~462K est; Model 3/Y 478,237</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Tesla's 486,532 Q3 deliveries top the ~462K Street number by ~24K and send TSLA +5.5% despite a 2.1% Y/Y decline.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Tesla released its Q3 2026 production, deliveries and energy-storage report Friday Oct 2 via 8-K. Total deliveries hit 486,532 — about 24K above the ~462K Wall Street consensus. Production came in at 464,391 and energy storage deployments were 13.7 GWh.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Model 3/Y did essentially all of the work with 478,237 deliveries; the 'Other Models' bucket (Cybertruck, Semi, Model S/X) fell to 8,295 — down 48% from 15,933 a year ago. YTD deliveries are 1,324,681, +8.8% vs the first three quarters of 2025.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
TSLA +5.5% on the delivery beat while Rivian (RIVN) -3% on a no-guide-raise reaction to its own record quarter — demand strength is uneven across EV names and name-selection matters. Full Q3 financials land Oct 22.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
EV traders, growth-tech desks, and auto sector analysts.
</p>
