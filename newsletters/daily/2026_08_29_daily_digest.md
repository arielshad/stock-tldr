<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Fed Chair Warsh's first Jackson Hole speech leans hawkish — 2Y yield +8bp to 4.31%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Warsh's Jackson Hole debut leans hawkish — inflation still 'above our 2 percent target', forward guidance 'has overstayed its welcome', and the 2Y yield jumps ~8bp to 4.31%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Fed Chair Kevin Warsh delivered his first Jackson Hole keynote — titled "In Our Time" — on Friday Aug 28, marking his 100th day at the helm. He stated: "Inflation is running above our 2 percent target. So the Fed's predominant focus right now should be on prices."
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Warsh said this summer's better-than-expected inflation readings "do not tell me that underlying trends have meaningfully improved" and called forward guidance a practice that "has overstayed its welcome" — signaling a shift toward data-driven, meeting-by-meeting policy. The fed funds range stays at 3.50–3.75% (unchanged since the 9-3 July hold).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Bond markets read it as hawkish: the 2Y note jumped ~8bp to 4.31%, its highest since late July, pricing in a higher probability of a rate hike. Equities gave back some weekly gains — S&amp;P 500 -0.25% to 7,711.76, Nasdaq -0.52% — though all three major indices still closed higher on the week.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, front-end rates desks, and FX — especially ahead of the August jobs report (Sep 5) and September FOMC decision (Sep 16–17).
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">PayPal (PYPL) -12.71% as Advent + Stripe walk from $53B LBO</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">One of the biggest-ever LBOs falls apart as Advent + Stripe walk away from a $53B PayPal takeout that PYPL's board wanted priced higher.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Bloomberg reported Friday Aug 28 that Advent International and Stripe have abandoned their $60.50/share bid for PayPal (valuing the company at ~$53B), after the board rejected the offer as inadequate. The deal would have been one of the largest leveraged buyouts in history.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
PYPL had rallied 40%+ during Q2 on takeover speculation; with the premium unwound, the stock fell as much as 16% premarket and closed -12.71% to $53.66 — roughly $6–7 below the withdrawn bid. The buyers could return later, but nothing is currently on the table.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The failed deal removes the largest listed-fintech LBO overhang from the private-equity pipeline. Advent and Stripe walking on price signals where mega-buyout valuations top out even for names trading at depressed multiples with activist campaign backing.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Fintech, event-driven, and merger-arb desks; private-equity LBO watchers tracking fintech deal flow.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Rubrik (RBRK) reported Q2 FY27 with revenue up 38% Y/Y to $427.3M (vs ~$396M est) and non-GAAP EPS of $0.20 — five times the $0.04 estimate. Management raised guidance for revenue, subscription ARR, and free cash flow across Q3 and FY27.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Subscription ARR grew 33% Y/Y to $1.66B (Cloud ARR $1.48B, +39%). Non-GAAP gross margin was 81.0% and FCF $65.7M. FY27 guidance: revenue $1.685–$1.693B, subscription ARR $1.88–$1.885B, and FCF $323–$333M — all raised.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Shares rallied 11.4% intraday to $107.13 (near the 52-week high) then reversed -6.85% AH to $99.69 as beat-and-raise fatigue set in after a strong August tape for high-multiple SaaS. It's the 10th straight quarter of outperformance since IPO.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Cyber and SaaS traders tracking data-resilience names (competes with Cohesity, Dell PowerProtect, Veeam).
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US July PCE — headline +3.7% Y/Y (0.1pt hot), core +3.3% Y/Y in line; Fed's preferred gauge stays sticky</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">July PCE hotter on the headline (3.7% Y/Y), core in line (3.3%) — inflation grinding sideways above the Fed's 2% target.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BEA released July 2026 Personal Income and Outlays on Wednesday Aug 26. The PCE price index rose 0.2% M/M and 3.7% Y/Y — unchanged from June and 0.1pt above consensus. Core PCE matched expectations at +0.2% M/M and +3.3% Y/Y.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Personal income rose 0.4% M/M and personal spending rose 0.2% M/M. Core PCE has now held at 3.3% Y/Y for three consecutive months. The release coincided with Q2 GDP (second estimate, unrevised at +1.5% annualized) and a surge in corporate profits (+$400.9B Q2 vs +$74.4B Q1).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The Fed's preferred gauge grinding sideways at ~3.3% core keeps the September FOMC path finely balanced. A hotter-than-expected headline without a core acceleration leaves rates-sensitive equities and long-duration Treasuries with less scope to price in near-term easing.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro and rates traders focused on the September FOMC path (decision Sep 16–17) and the next catalyst: August jobs report (Sep 5).
</p>
