<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Blockstream halts Liquid Network after ~4,000 BTC ($320M) drained from federation reserves via SideSwap PAK exploit</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Bitcoin's oldest sidechain got emptied Sunday: 4,000 BTC left the federation wallet through a valid peg-out path Blockstream can't yet explain.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Liquid Network — the Blockstream-run federated Bitcoin sidechain — paused operations Sunday Sept 6 after roughly 4,000 of the ~4,200 BTC held in a federation wallet (~$320M) exited reserves. The withdrawal flowed through a legitimate Peg-Out Authorization Key tied to federation member SideSwap; no PAK or signing key was stolen, pointing to a software validation failure.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Liquid's peg mechanism requires both a valid PAK and federation functionary signatures — in this incident the PAK check passed despite no stolen keys, pointing to a bug in the Elements codebase. Blockstream disabled bridge nodes, told exchanges to suspend L-BTC deposits/withdrawals, and is coordinating a patched restart. Non-BTC assets like USDT and DePix on Liquid are unaffected.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Liquid has been the reference L2 for institutional Bitcoin settlement since 2018 — this is the largest reserve exit in its history and the first full halt. The actor claims "white hat" status and proposes returning funds after a patch; if that framing doesn't hold, Blockstream faces a $320M reserve shortfall against issued L-BTC.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
BTC L2 operators, prime brokers, sidechain risk desks.
</p>

NVIDIA confirmed on Thursday Sept 3 it will acquire Hugging Face — the open-weight AI hub used by more than 18 million developers — for $12.93 billion all-cash. Founder-CEO Clem Delangue approached Jensen Huang weeks before the deal; Hugging Face will remain an open, multi-cloud platform under NVIDIA ownership.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Hugging Face hosts 3M models, 500K datasets, 1M applications and posted ~$150M in annualized revenue as of August 2026 after raising $395M in venture funding since 2016. Closing is expected in the first half of 2027 subject to regulatory clearance; existing multi-cloud and non-NVIDIA hardware support will continue.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
NVDA is expanding from a hardware supplier into the AI software distribution layer — the on-ramp where developers pick models. It also blunts the competitive risk that a rival hyperscaler could buy the hub and steer developers to non-NVIDIA silicon. NVDA rose 2.53% Thursday and another 1.8% Friday, briefly approaching an all-time high.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI infrastructure investors and semis traders.
</p>
