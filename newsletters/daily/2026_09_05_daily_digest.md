<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">August NFP hit +162K vs a +53K consensus, unemployment held at 4.1%, and rate-hike odds for the Sept 15–16 FOMC jumped to ~58%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Bureau of Labor Statistics' Employment Situation for August 2026, released Friday Sept 4 at 8:30 a.m. ET. Nonfarm payrolls rose by 162,000 versus a Dow Jones consensus of 53,000 — nearly triple expectations, the strongest gain since March.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Average hourly earnings rose +0.3% M/M to $37.75. Prior months were revised up: June from +20K to +31K, July from -23K to +21K — a net +55K upward revision that amplifies the beat.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The blowout print reversed this week's dovish Fed drift. Futures moved to ~58% odds of a Sept 15–16 hike (from ~55%); 2Y yields rose 4bp to 4.37%, 10Y ticked to 4.77%. Bitcoin briefly broke $80K before recovering.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Rates desks, macro traders, and FOMC watchers heading into the Sept 15–16 decision — with August CPI (Thurs Sept 11) the next key input.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
