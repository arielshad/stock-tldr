<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Unanimous 12-0 vote at Warsh's fourth meeting; SEP median funds rate for end-2026 rises to 4.1%. Dow -631 pts, 10Y tops 5.04% intraday.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The FOMC raised the fed funds target range 25bp to 3.75–4.00% on a unanimous 12-0 vote — the first hike in roughly three years. Chair Kevin Warsh struck a hawkish tone at his press conference, citing persistent inflation.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The September Summary of Economic Projections shifted the median fed funds rate to 4.1% for end-2026, implying one more 25bp move. Median 2026 PCE inflation was projected at 3.7% (core 3.4%), unemployment at 4.1%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The first hike in three years cements the Warsh Fed's pivot to active tightening. The 10-year yield topped 5.04% intraday — the first breach since October 2023 — while the Dow fell 631 points and rate-sensitive financials led losses.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, and allocators managing duration exposure heading into a possible second hike before year-end.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Senate voted 49-50 on Tuesday to block cloture on the Digital Asset Market CLARITY Act — which would have split regulatory jurisdiction over digital assets between the SEC and CFTC and created a registration framework. Cloture needed 60 votes; the motion fell 11 short.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Crypto equities had been priced for passage after Monday's anticipation rally. Coinbase (COIN) dropped 10.1% on 2.15× average volume, Circle (CRCL) -11.4%, BTC slipped ~4% toward $75.7K, and XRP fell ~10% on SEC-CFTC classification uncertainty.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Crypto-equity traders, DC-policy watchers, and stablecoin issuers whose regulatory future depends on the SEC/CFTC jurisdictional split.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Corning (GLW) -13.7% — biggest drop since July 28 — after quiet $2B at-the-market equity filing with Goldman Sachs</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Optics peers dragged lower: Coherent -11%, Lumentum -9%, Fabrinet -6% — market reads the ATM as unplanned dilution to fund AI-optics capex.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Corning filed an 8-K after Friday's close disclosing an Equity Distribution Agreement with Goldman Sachs allowing the company to sell up to $2B of common stock "from time to time" via an at-the-market program. Shares gapped down Monday and closed -13.7% at $143.60.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Unlike a conventional secondary, an ATM sets no fixed price or share count — Goldman drips shares into the open market at Corning's direction, taking a 1% commission. Net proceeds are earmarked for "general corporate purposes" with no disclosed spending target.
