<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Moderna (MRNA) +176.97% — first-ever Phase 3 win for an mRNA cancer therapy</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">MRNA nearly triples on Wed Aug 19 as the first Phase 3 mRNA cancer therapy readout — intismeran + KEYTRUDA — cuts melanoma recurrence.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Moderna and Merck reported positive Phase 3 topline data from the INTerpath-001 trial pairing intismeran autogene with KEYTRUDA in resected stage IIB–IV melanoma. The combination met the primary endpoint of recurrence-free survival and a key secondary endpoint of distant metastasis-free survival — the first successful Phase 3 readout for any mRNA-based cancer therapy.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
INTerpath-001 randomized 1,137 patients 2:1 to intismeran (a personalized mRNA neoantigen vaccine) plus KEYTRUDA versus KEYTRUDA alone. MRNA closed +176.97% at $174.38 on 199.3M shares (~19× average); MRK surged +12.6% and BNTX +22%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the platform-validating readout the mRNA-oncology thesis has waited years for — a genuine Phase 3 win that re-anchors Moderna's cancer pipeline, lifts mRNA peers, and adds ~$44B in market cap in a single session. Merck plans to begin regulator talks within months.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Biotech, healthcare, and mRNA platform investors tracking the next catalyst: overall survival readout and regulatory filings.
</p>

<strong style="color: #f7ff00;">What is it?</strong><br>

Dissenters Hammack, Kashkari, and Logan all preferred an immediate 25bp hike, and participants warned "policy tightening would likely be necessary" if inflation doesn't cool.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The hawkish tone lowers odds of a September cut and raises the bar for incoming CPI/jobs prints. The muted equity reaction (SPX +0.21%) was mostly a Treasury-buyback offset; without it, the read-through would have been more clearly negative for duration.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, and Fed watchers ahead of Jackson Hole (Aug 27–29) — Warsh's first keynote as Chair.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Treasury doubles long-bond buyback caps to ≥$4B — 30Y yield falls ~15bp, dollar drops most in 3 weeks</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Bessent's Treasury doubles long-bond buyback caps to at least $4B a pop, lopping ~15bp off the 30Y yield and sinking the dollar in a surprise mid-quarter intervention.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Less than 24 hours after the 30-year Treasury yield hit 5.337% (highest since 2007), the U.S. Treasury announced it will "at least double" liquidity-support buyback ops for longer-dated coupon securities — from $2B to ≥$4B per operation — effective Sept 9 through Nov 4.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Post-announcement, the 30Y yield dropped ~15bp to 5.184%; the 10Y fell ~6bp; DXY had its biggest one-day decline in three weeks; gold rose ~3.7% to $4,493/oz and silver crossed $65/oz. Total operations through the Nov 4 refunding could aggregate ~$83B.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Treasury is signaling it will step outside routine calendar operations to cap the long-end selloff — a de-facto yield ceiling that also softened the hawkish July FOMC minutes released hours later. TLT and long-duration equity get a tailwind; the dollar faces headwinds.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Rates traders, duration allocators, and dollar/gold macro desks watching the Jackson Hole (Aug 27–29) and November refunding calendars.
</p>
