<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Bitcoin Crashes to Two-Year Low Near $55,130</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Bitcoin prints a two-year low at $55,130 as Friday's AI selloff spills into the crypto complex; Strategy drops below its BTC cost basis.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
After the Nasdaq fell 5.3% on Friday, selling continued overnight into Saturday Nov 21 when Bitcoin reached $55,130—its weakest print since September 2024—before rebounding ~9% to around $60,300 by early afternoon ET.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
CoinGlass tallied ~$1.8B in leveraged crypto liquidations over 24h (~$1.3B longs); BlackRock's IBIT recorded $541.1M of outflows on Thursday Nov 19—its largest single-day outflow since its January 2024 launch—pushing US spot BTC ETF weekly outflows to ~$1.1B.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
CryptoQuant called it "extreme capitulation"—holders realized ~$11.3B of losses over seven days, roughly 8× the gains. Strategy (MSTR) finished the week down 30.3% at $77.80, now trading with Bitcoin below its ~$75,452 average cost basis.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Crypto desks, MSTR holders, and macro traders tracking risk-asset contagion from equities into digital assets.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Intuit Beats Q1, Sells Mailchimp for $3.68B, Cuts Full-Year Guide</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Intuit beats Q1 and agrees to sell Mailchimp to Bending Spoons for $3.68B—a sharp write-down from the $12B it paid in 2021—but trims FY27 guidance on Credit Karma weakness; shares −12.8%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Intuit reported fiscal Q1 2027 (quarter ended Oct 31) with revenue $4.354B (+12%) and non-GAAP EPS $2.91 (+56%), both above estimates, and announced it will sell Mailchimp to Italy's Bending Spoons for ~$3.68B ($3.31B cash + $368M stock), closing early 2027.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Management trimmed FY27 revenue guidance to $23.08–$23.37B (+8–9%) from a prior higher range, citing a slower Credit Karma tied to higher rates and AI-driven search shifts; full-year non-GAAP EPS guidance of $22.88–$23.12 was reiterated. Intuit plans to deploy the Mailchimp cash proceeds into buybacks.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Intuit paid ~$12B for Mailchimp in 2021 and is selling it for $3.68B—a stark implied write-down. Credit Karma's deceleration is a read-across for NerdWallet (NRDS) and other financial-lead-gen models facing rate + AI headwinds.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Fintech and software investors; anyone holding exposure to credit-lead-gen or email-marketing platforms.
</p>
