<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">U.S. July 2026 Jobs Report — Nonfarm Payrolls -23K, First Monthly Loss Since 2020</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">BLS July NFP -23K vs +80K est — the first monthly decline since December 2020. Prior two months revised -103K combined; S&P sets a fresh record as September Fed-hike odds crater 57% → 44%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Bureau of Labor Statistics' July 2026 Employment Situation showed nonfarm payrolls declined by 23,000 versus a +80K consensus — the first monthly loss since December 2020. The unemployment rate ticked to 4.1% from 4.2%, but only because workers left the labor force.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Prior months were revised -103K combined (May to +63K, June to +20K), with losses led by local government education (-50K), leisure & hospitality (-40K), and retail (-19K). The 10-year Treasury fell ~6bp to ~4.62%, the S&P 500 closed at a record 7,757.64 (+0.62%), and September Fed-hike odds slid from 57% to 43.9%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the cleanest labor-side challenge yet to Chair Warsh's hawkish tilt — a negative payrolls print with large downward revisions puts the case for another hike under real stress. Next week's CPI (August 13) is now the swing variable.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, front-end rates desks, and Fed-watchers tracking the path to an October rate cut.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">AppLovin's Q2 revenue and Q3 guide both fall short of Street estimates in what Piper Sandler called its first guide miss since going public — AXON model deceleration is the culprit.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
AppLovin reported Q2 2026 revenue of $1.924 billion (+52.8% Y/Y), falling $26 million short of the $1.95 billion consensus. Adjusted EBITDA of $1.614 billion (84% margin) also missed by ~$26 million, while GAAP EPS of $3.76 roughly met estimates at $3.75.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Q3 revenue guidance midpoint of $2.07 billion came in below the $2.08 billion estimate and Q3 adj EBITDA guide of $1.73 billion was below $1.75 billion expected. Management attributed the shortfall to slower-than-normal model improvements in the gaming-focused AXON ad network.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
