<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US Wireless Carriers Crater — SpaceX Buys Grain 800 MHz Spectrum for Starlink Mobile</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">SpaceX locks in low-band spectrum for Starlink Mobile; T-Mobile, Verizon, AT&T all crater as a satellite-first mobile rival takes shape.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
SpaceX announced Thursday Oct 8 that it will acquire 100% of Grain Management's 800 MHz spectrum portfolio — up to 14 MHz of paired low-band spectrum — for Starlink Mobile. The deal is subject to FCC approval; WSJ reports SpaceX will pay roughly $8B in cash.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Grain had acquired the 800 MHz portfolio from T-Mobile in August 2026 for $2.9B. On Friday Oct 9 the Big Three carriers sold off hard: TMUS -13.27% to $148.58, VZ -8.75% to $41.65, and T -9.81% to $22.18; SpaceX (SPCX) rose 1.25% to $162.57.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Low-band 800 MHz penetrates walls and roofs — the gap in SpaceX's existing high-band EchoStar portfolio that forced analysts to view Starlink Mobile as a coverage layer, not a Big Three substitute. With this block in hand, SpaceX can credibly target "major mobile carrier" status in the US.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Telecom equity desks, satellite/space investors, tower REIT holders watching a new infrastructure entrant emerge.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Delta Air Lines (DAL) Q3 FY26 — FY26 EPS Guide Cut to $5.10–$5.60 as $6B Fuel Bill Hits</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Delta's Q3 adj EPS beats last year by $0.02 but FY26 EPS guide gets cut to $5.10–$5.60 as a $6B fuel bill eats the plan.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Delta Air Lines reported Q3 FY26 (ended Sept 30) before the open Friday Oct 9, kicking off the earnings season. Adjusted EPS came in at $1.72 (vs $1.70 a year ago) on adjusted revenue of $17.6B (+16% Y/Y); the headline move was the full-year 2026 EPS guide cut to $5.10–$5.60 from the $6.50–$7.50 range reaffirmed in July.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
GAAP EPS fell to $1.15 from $2.17 a year ago as fuel pressure hit the bottom line. Q4 2026 guide is adj EPS of $1.15–$1.65 on ~20% revenue growth; the company plans ~$2.5B of full-year FCF and over $2B of debt paydown.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Fuel is the swing factor — Delta flags a $6B full-year fuel cost increase driven by the OPEC+/Hormuz-era crude backdrop. The lower EPS range (midpoint ~$5.35 vs prior ~$7.00) sets a cautious tone heading into bank earnings Oct 13–14 and peer airline prints later this month.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Airline investors, earnings-season macro traders, and energy desks tracking fuel-cost beta across the US4 carrier group.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Headline beat with a guide cut — PepsiCo trims FY26 EPS growth sharply and promises "additional structural cost reduction" actions.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Crescent doubles down on Eagle Ford consolidation — $3.85B net for Devon's Karnes Trough assets, $2B JPM/RBC bridge.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Viatris (VTRS) to Acquire Pacira BioSciences (PCRX) at $36.50/Share — ~44.8% Premium, ~$1.65B Deal</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Viatris pays a 45% premium for Pacira's non-opioid pain franchises — EXPAREL + ZILRETTA bolt in at ~$1.65B.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Thursday Oct 8 Viatris (VTRS) announced a definitive agreement to acquire all outstanding Pacira BioSciences (PCRX) shares at $36.50/share in cash, valuing Pacira equity at ~$1.65B — a ~44.8% premium over Pacira's $25.20 close on Oct 7. The deal is structured as a 10-business-day tender offer followed by a second-step merger.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Pacira's two in-market, patent-protected products are EXPAREL (bupivacaine liposome injectable) and ZILRETTA (triamcinolone acetonide ER). On a TTM basis through June 30, Pacira generated ~$746M revenue and ~$177M adjusted EBITDA. Viatris calls it immediately accretive to its financial guidance metrics; close expected by end of 2026.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The ~44.8% premium is on the high end for mid-cap specialty-pharma deals, signaling Viatris wants non-opioid pain as a durable growth engine insulated from generic/biosimilar price erosion. PCRX +~44% to ~$36.31 (near offer); VTRS -1.1% as the market digests the leverage path.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Specialty-pharma M&A desks and biotech event-driven funds tracking the tender timeline and HSR clearance.
