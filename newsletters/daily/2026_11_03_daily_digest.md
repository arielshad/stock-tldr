<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Apple's September quarter sets records in revenue, iPhone and EPS, but a soft December-quarter gross-margin outlook sends shares ~-2.8% after hours.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Apple reported fiscal Q4 2026 (quarter ended Sept 26) after the close on Nov 2 — CEO John Ternus's first earnings call since succeeding Tim Cook on Sept 1. Revenue of $114.5B (+12% Y/Y) and diluted EPS of $2.10 (+14%) both set September-quarter records; FY26 full-year revenue of $479B was an all-time record.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
iPhone $57.58B (September-quarter record) and Services $31.57B (all-time high) led the beat. Gross margin was 47.9%, including ~1pp of tariff-refund benefit. Apple returned $28B to shareholders in Q4 and declared a $0.27/share dividend payable Nov 16.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Shares fell ~-2.8% after hours on a soft December-quarter gross-margin outlook and an iPad miss ($6.23B, light vs. estimates). Services' all-time high keeps the services-mix story intact, but the margin bridge cuts against the hoped-for tariff-refund cushion.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Mega-cap holders, consumer-tech desks, and index allocators watching the AAPL multiple.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Binance $6.3B Security Breach — Largest Crypto Hack Ever; FBI Blames North Korea's TraderTraitor; 90% Backed from SAFU</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Binance says a $6.3B hot-wallet exploit — the largest crypto theft ever — is 90% backed from company funds, with the FBI pointing to North Korea.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
On Oct 29 Binance disclosed a breach that drained ~$6.3B of client tokens from its hot wallets — the largest crypto exchange hack on record. Withdrawals were suspended; by Saturday the FBI publicly named TraderTraitor (a North Korean state-sponsored unit) as the attacker.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
A compromised DevOps engineer's laptop gave access to batch-withdrawal signing infrastructure. ~$3B was frozen on-chain by Tether ($1.567B USDT), Circle ($800M+ USDC), Ripple and others. Binance earmarked $6.34B from its SAFU reserve, Futures Insurance Fund, and treasury — with 90% replaced by Saturday.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
BTC fell ~5% to $77K, BNB dropped 8%, and ETH fell 5.7% on the news. The event tests whether SAFU can absorb a nine-figure loss without user socialization and sets a new benchmark for on-chain asset-freeze response time.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Crypto desks, exchange risk managers, and stablecoin issuers tracking on-chain freeze infrastructure.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">BOJ holds at 1.25% but hikes its inflation forecast and triples the ETF-unwind pace, with Takata voting for an immediate hike to 1.50%.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The Bank of Japan's Policy Board voted 8–1 on Oct 30 to hold the short-term rate at 1.25%, with hawkish board member Hajime Takata dissenting for a quarter-point hike to 1.50%. The decision was paired with an updated Outlook Report and a separate ETF-disposal acceleration.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The FY2027 core CPI forecast was raised to 2.6% from 2.4% in July; the statement describes underlying inflation as "at a level generally consistent with" the 2% target. Separately, the BOJ raised the ETF-sales pace to ~¥860B/yr from January (vs. ~¥330B/yr previously), cutting the implied unwind timeline from ~112 years to ~43 years.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

Markets now price ~80% odds of a December hike; Reuters-polled economists see the policy rate at 1.5% by December and ~1.75–2.0% terminal by end-2027. USD/JPY briefly dipped below 157.50; the accelerated ETF sales reinstates a visible drag on Japanese equity flows.
