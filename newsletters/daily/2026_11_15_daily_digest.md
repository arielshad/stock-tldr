<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Nvidia (NVDA) CEO Jensen Huang Resigns — CFO Named Interim CEO</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Jensen Huang steps down as Nvidia CEO; CFO Colette Kress named interim leader while board searches for permanent successor.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>

Every equity investor, AI-infrastructure allocators, and risk desks watching the most consequential leadership transition in US tech in a decade.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">US October PPI +6.5% Y/Y — Highest Since Nov 2022, December Fed Hike at ~89%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">October producer prices cool month-over-month but the 12-month rate climbs to 6.5% — highest since Nov 2022 — hardening the Fed's case for a December rate hike.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The BLS October 2026 PPI for final demand rose +0.3% M/M (vs +0.4% est) — a cooldown from September's upwardly-revised +1.4% — but the 12-month rate climbed to +6.5%, the largest annual increase since November 2022.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Goods prices surged +10.2% Y/Y (largest since Oct 2022); services rose +0.2% M/M for a fifth straight month. Core PPI (ex food, energy, trade services) rose +0.5% M/M for a second straight month, +4.9% Y/Y.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
CME FedWatch now shows ~89% odds of a 25bp hike at Dec 8–9 FOMC (target to 4.00–4.25%). Capital Economics sees consecutive Dec + Jan hikes as the most likely path.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, and Fed watchers with exposure to short-duration Treasuries and rate-sensitive equities into year-end.

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
