<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Fed Hikes 25bp to 3.75–4.00% — First Rate Hike Since 2023</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Fed hikes 25bp to 3.75–4.00% on a unanimous 12-0 vote — first hike since 2023, dot plot signals one more this year.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The FOMC raised the target range for the federal funds rate by 25 basis points to 3.75–4.00% at its September 15–16 meeting — the first hike in roughly three years. The move was widely expected; Chair Kevin Warsh's press conference struck a hawkish tone on persistent inflation.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Vote was unanimous 12-0. The September SEP shifted the median federal funds rate to 4.1% for end-2026 (implying one more 25bp move), with median 2026 PCE inflation projected at 3.7% and core PCE at 3.4%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
First hike in three years cements Warsh's pivot to active tightening. The 10-year Treasury topped 5.04% intraday — the first breach since October 2023 — while the Dow fell 631 points and the S&P 500 dropped 0.45%.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rates desks, and allocators across every asset class.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">SEC Opens 5-Year On-Chain Lane for Tokenized US Stocks — HOOD/COIN/CRCL +3–5%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">SEC opens a 5-year on-chain lane for tokenized US stocks after Congress's crypto bill stalls.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Chair Atkins's SEC issued a 5-year conditional exemptive order letting Tokenized Securities Venues trade tokenized NMS stocks via permissioned AMMs and liquidity pools — without registering as an exchange. The move came two days after the CLARITY Act's Senate cloture failed 49-50.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
TSVs must be US-based, sanctions-compliant, and transparent. Tokenized stocks must be true digital twins — same dividends and voting rights as the underlying; purely synthetic products are excluded. Anti-fraud and anti-manipulation rules apply in full.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This gives Robinhood, Coinbase, Circle, and Securitize a workable 5-year sandbox to launch on-chain equities in the US — the same product BlackRock and DTCC have prototyped abroad. HOOD, COIN, and CRCL each added 3–5%, partially recouping their post-CLARITY-fail selloff.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Crypto-exchange traders, tokenization/RWA desks, and market-structure watchers.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Fluence Energy (FLNC) -14–22% — Second FY26 Guide Cut Swings EBITDA to -$200M Loss</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Fluence cuts FY26 for the second time this year and swings adj EBITDA guide from ~breakeven to a ~$200M loss.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Battery-storage integrator Fluence Energy pre-announced a fresh FY26 guidance cut after Tuesday's close. Revenue is now expected at ~$2.4B (vs $2.9–3.1B in August and $3.2–3.6B originally), and adjusted EBITDA has swung to a ~$200M loss from a prior near-breakeven midpoint.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
CEO Julian Nebreda attributed the cut to continued ramp delays at Fluence's Houston battery-module manufacturing facility. Baird slashed its price target 70% and downgraded the stock, calling repeated cuts a "material negative." Shares dropped 13.9% in the session and traded as much as -22% intraday.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the second FY26 guide cut in ~5 weeks — investor patience is gone. It removes FLNC from the AI-power/data-center storage playbook near-term and hands share to Tesla Megapack; the pattern also pressures other domestic ESS assemblers with IRA-linked customer bases.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Clean-tech/battery-storage traders and IRA/domestic-content watchers.
</p>
