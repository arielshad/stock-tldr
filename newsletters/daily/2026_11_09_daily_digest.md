<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">China October PPI +5.7% Y/Y — fastest since June 2022 — as CPI slows to +0.7%</h2>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
China's NBS released October 2026 inflation data: PPI rose to +5.7% Y/Y (beat +5.3% est), the fastest since June 2022, while CPI slipped to +0.7% Y/Y (missed +0.8% est). CSI 300 rose 0.56% on the release.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
PPI acceleration was driven by mining and raw materials; Pinpoint Asset Management's Zhang Zhiwei attributed it to "very strong external demand." CPI decelerated as food prices fell more than expected; core CPI also eased to +0.8% from +1.0% prior.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The widening producer-vs-consumer gap signals hot external demand lifting China's upstream complex while domestic demand stays weak. A hot PPI also trims PBOC room for aggressive near-term stimulus; iron ore, base metals, and USD/CNY are the natural read-throughs.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro desks, Asia FX, iron ore/base metals traders, EM equity.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">DraftKings (DKNG) burns $1B+ of 2026 EBITDA guidance for Predictions push — stock -21%</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">DKNG burns down 2026 EBITDA guidance by over $1B to fund a $650–$700M Predictions-market push. Shares -21% Friday.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
DraftKings reported Q3 2026 after Nov 5's close: revenue $1.329B (+16% Y/Y) below ~$1.4B est; FY26 adj EBITDA guide slashed from +$700–$900M profit to a $(175)–$(275)M loss as the company pours $650–$700M into its Predictions event-contract markets.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Sportsbook net revenue grew +36% with a >11% hold rate, and 1.6M customers have engaged with Predictions YTD. October annualized Predictions volume hit $56.8B (5x July). FY27 targets introduced: $7.35–$7.75B revenue, $800M–$1.0B adj EBITDA.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
This is the clearest signal yet that sports-betting incumbents treat event-contract platforms as an existential threat. Flutter (FLUT) said Predictions had "limited impact" — DKNG's response is the exact opposite stance, burning more than $1B of near-term profit to defend turf.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Sports-betting investors, consumer-discretionary funds, event-contract watchers.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Lam Research (LRCX) authorizes new $25B buyback + $0.33 quarterly dividend — stock +11% premarket</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Lam Research board authorizes a $25B share repurchase (on top of ~$4.04B remaining from prior program) and a $0.33 quarterly dividend; shares +11% in Fri premarket.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Lam Research's board authorized a new $25B share repurchase program, with ~$4.04B remaining from the prior program still available as of June 28 fiscal year-end. The board also declared a $0.33 quarterly dividend payable January 6, 2027 to holders of record December 2.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The new $25B authorization replaces and significantly exceeds the prior program's remaining balance. Combined with dividends, the capital-return program signals management confidence in the wafer fab equipment cycle outlook heading into 2027.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
A $25B buyback from a semicap company is one of the largest capital-return announcements in the sector's history. The timing — amid a broader chip-sector selloff (SOX -11% the same week) — amplifies the confidence signal and sets up LRCX as a capital-allocation story alongside its WFE cycle exposure.
