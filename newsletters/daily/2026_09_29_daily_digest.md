<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
A buyback of this size (~5–6% of NVDA's ~$4T market cap over 15 months) is a meaningful EPS tailwind and puts a persistent institutional bid under the stock. It signals management's confidence in sustained AI capex cash generation with forward P/E compressed to ~24x.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Bitget confirms $387.5M hot-wallet hack — largest crypto theft of 2026 — CEO names North Korea suspects; withdrawals frozen, restart plan underway</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Attackers spoofed transaction data through a compromised Bitget backend to drain $387.5M — the biggest crypto exchange heist of 2026.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Bitget detected unauthorized transfers from its hot and warm wallets at 18:31 UTC on Thu Sept 24. CEO Gracy Chen confirmed the total at $387.5M by Fri Sept 25 after Zcash and TRON balances were added — the largest single centralized-exchange theft of 2026.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Attackers compromised a backend system and spoofed transaction data to trigger Bitget's own authorization process — private keys were not stolen and cold wallets were untouched. Funds moved across 9+ chains. Bitget's ~$464M User Protection Fund covers the full loss; withdrawal restart began Sept 28 (BTC), continuing through Oct 2.
</p>
