<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
First direct US strikes on Iranian-flagged oil tankers of the 2026 war. The IRGC launched ballistic missiles at a US aircraft carrier and a guided-missile destroyer — both ships evaded, no American personnel were hurt. Hours later CENTCOM struck three IRGC crude oil carriers.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
M/T Downy was permanently disabled off Kharg Island (Iran's main crude export terminal), M/T Stark 1 near Jask, and M/T Kylo (aka Noxen) was destroyed in the Gulf of Oman after crew evacuation. Admiral Brad Cooper: "If you shoot at two of our ships, we will impose an even higher economic cost."
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Introduces a new US "tanker-for-tanker" rule of engagement targeting the IRGC's shadow oil network. Brent settled Friday at $96.28/bbl (+9% w/w), with further upside risk Monday — Kharg handles up to 90% of Iranian crude exports.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Energy desks, macro traders, defense contractors, shipping/tanker equities.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Tesla (TSLA) -5.92% to $354 — muted Cybercab Austin launch + NHTSA opens Audit Query AQ26002 into self-certification</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Muted Austin Cybercab launch and a same-day NHTSA audit into self-certification knock TSLA back below $360.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Tesla began commercial Cybercab rides in a geofenced area around Austin on Thursday Sept 3 — invite-only, no livestream, no Elon Musk. The next day NHTSA opened Audit Query AQ26002 into Tesla's self-certification of the vehicle, covering roughly 1,000 Cybercabs.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
NHTSA's Office of Defects Investigation is examining the process and technical data Tesla used to self-certify the Cybercab — which has no steering wheel, brake pedal, accelerator or conventional mirrors — as compliant with Federal Motor Vehicle Safety Standards. TSLA closed Fri at $354.08 on 64.4M shares (~53% above 3-month avg).
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The audit query targets Tesla's central bet — that a driverless car can be self-certified without the Part 555 exemption process. Amazon's Zoox took four years on that alternative route and faced a recall. If Tesla is pushed there, the Cybercab hits a 2,500-unit annual cap.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
TSLA holders, AV-regulation watchers, robotaxi supply-chain names.
</p>
