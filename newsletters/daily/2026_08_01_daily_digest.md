<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">KOSPI +17.9% — Biggest Single-Day Gain in Korean Market History</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">KOSPI logs its biggest one-day gain ever as Asia AI trade snaps back on Microsoft + Amazon cloud blowouts.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
South Korea's KOSPI closed Friday July 31 up 17.9% at 6,695.45 — its largest ever single-day percentage gain, exceeding the prior ~12% record from October 2008. SK Hynix hit the 30% daily up-limit and Samsung Electronics surged 28%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The rally came after Microsoft reported Q4 FY26 Azure growth of 43% cc and Amazon posted AWS +36.7% Y/Y, both signaling that hyperscaler AI capex is translating to real cloud revenue — directly reversing the AI-bubble narrative that had pushed KOSPI down 17% over the three prior sessions. Nikkei +4%, Taiwan Taiex +8%, TSMC ADR +10%.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The move ranks as the largest ever recorded in a G20 equity index and unwinds most of the July 17 SOX-bear-market panic in a single session. It confirms Korean memory and semi-cap exporters remain the highest-beta expression of US hyperscaler AI capex.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
AI semi-cap traders and EM equity desks — and anyone watching how NVDA, MU, and AVGO trade heading into NVDA's August print.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Amazon crosses $200B in a single quarter for the first time as AWS accelerates to 37% growth and operating income jumps 43%.</p>

<strong style="color: #f7ff00;">What is it?</strong><br>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

Shares dropped ~3-4% in extended trading on Tim Cook's final earnings call before handing the CEO role to John Ternus on September 1.

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">The Fed's preferred wage gauge cools less than expected as real wages for private workers fall for the first time in four years.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Nominal wages and salaries rose 3.2% Y/Y, but Iran-conflict energy prices pushed CPI higher through Q2 — erasing real purchasing power even as paychecks grew. Benefit costs rose a faster 3.8% Y/Y, keeping total compensation elevated.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
ECI is the Fed's preferred mix-adjusted wage measure. A hotter-than-expected print stiffens the Hammack/Kashkari/Logan hike-dissent camp from the July 29 FOMC, while real-wage compression creates a consumer-spending headwind that complicates the path for Chair Warsh.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Macro traders, rate-vol desks, and Fed-watchers ahead of the August 7 NFP and August 12 CPI.

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
